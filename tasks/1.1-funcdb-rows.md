# Task 1.1: tools/funcdb.py, one row per game function

**Goal.** A new script `tools/funcdb.py` writes `build/funcdb.tsv`: one row for
every function in the game code of all six binaries, with its size, status and
blocker class. Tasks 1.2–1.4 add columns, the queue and a check to the same script.

**Read only these** (keep your context small):
- `tools/autodecomp.py` lines 38–63: `ALABEL` and `functions(binary)`. Note
  `functions()` returns only functions still in `asm/`.
- `tools/readme_progress.py`: `tracked_src()` and `progress_stats()`. Your
  totals must equal `progress_stats()`; copy how it finds starts and ends.
- `tools/progress.py`: `BINARIES` and `region(binary, addr)`; a function counts
  only when `region()` is `"game"` or `"text"`.

**Rows.** Function starts come from two places:
- every `glabel` function in `asm/<bin>/*.s`, with its asm text from
  `glabel` to `endlabel`;
- every `src/<bin>/**/*.c*` file whose first line is `// range: 0xSTART 0xEND`
  (tracked or not, including `asmfunc/`), with the file text as its body.

`size` = END − START for src files, otherwise the next start − START (the same
rule as `progress_stats()`). Skip the last function of a binary when it has no
end, and skip any start outside the game/text regions.

**Columns, this task** (tab-separated, one header line, rows sorted by
`BINARIES` order then address):

| Column | Value |
|---|---|
| `binary` | `SLES_539.74`, `TITLE`, `SHOP`, `MENU`, `CASINO`, `BATTLE` |
| `func` | `func_XXXXXXXX` (the glabel or the src file's stem) |
| `addr` | `0x%08X` |
| `size` | bytes, decimal |
| `status` | `matched` = src file tracked by git and not under `asmfunc/`; `asmfunc` = under `src/*/asmfunc/`; `untracked` = other src file on disk; `asm` = only in `asm/` |
| `last_result` | the **last** value for this func in `build/autodecomp_<bin>.tsv` (`name<TAB>result` lines), or `-` |
| `blocker` | `-` for `matched`. Otherwise the first that applies: `entry-inside` if the body matches `ALABEL`; `jumptable` if the body contains `jtbl_`; `hilo` if `last_result` is `link`; else `none` |

Leave room for the columns task 1.2 adds (`callers`, `callees`, `strings`,
`tu`): write the rows through one function that takes a dict, so adding
columns later is one line.

**CLI.** `tools/funcdb.py` (no arguments) writes `build/funcdb.tsv` and prints
one summary line per binary: `<bin> <rows> rows, <bytes> bytes`.

**Commit.** `tools/funcdb.py` alone, through the gate:
`funcdb: one row per game function with size, status and blocker`.
