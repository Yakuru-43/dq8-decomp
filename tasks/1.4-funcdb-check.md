# Task 1.4: funcdb.py --check, the Phase 1 gate

**Goal.** One command proves that every remaining function is in the database
and the queue with a blocker class, and prints the counts per blocker. This
is the Phase 1 gate in `tasks/PLAN.md`.

**Read only:** `tools/funcdb.py` and `tools/readme_progress.py` (`progress_stats`).

**`tools/funcdb.py --check`** reads `build/funcdb.tsv` and `build/queue.tsv`
(it does not rebuild them) and fails if any of these is false:
1. For each binary, the funcdb row count and the sum of `size` equal
   `progress_stats(binary)`'s `funcs_total` and `bytes_total`.
2. The number of `matched` rows per binary equals `funcs_done`.
3. Every non-`matched` row has `blocker` in `none`, `jumptable`,
   `entry-inside`, `hilo`, and every `matched` row has `-`.
4. Every non-`matched` funcdb row has exactly one queue row with the same
   `(binary, func)`, and the queue has no other rows.
5. Every queue `state` is one of the five states, and `since` is a valid date.

It prints the problems, at most 20 lines, then a table, then `check: PASS` or
`check: FAIL`. Exit 0 or 1.
```
blocker        functions        KB
none                7658      2375
jumptable            130       201
entry-inside         128        55
hilo                 130        46
total               8046      2677
check: PASS
```
KB = sum of `size` / 1024, rounded.

**Commit.** `tools/funcdb.py` alone, through the gate:
`funcdb: --check, every remaining function has a row and a blocker`.
Then tick 1.4 and write "Phase 1 gate passed" plus that table in `notes/weekly/`.

   Rebuild with `tools/funcdb.py`.
