# Task 1.2: funcdb.py adds callers, callees, strings and a translation-unit guess

**Goal.** Four more columns in `build/funcdb.tsv`, appended after `blocker`
in this order: `callers`, `callees`, `strings`, `tu`.

**Read only:** `tools/funcdb.py` (your task 1.1) and one data file to see the
string format, e.g. `grep -m5 asciz asm/SLES_539.74/data/*.s`.

**callees.** From an asm body: every `jal func_XXXXXXXX` and `j func_XXXXXXXX`
target. From a src file: every `func_XXXXXXXX` followed by `(` (`\bfunc_[0-9A-F]{8}\s*\(`),
excluding the function itself. Sorted, comma-separated, unique; `-` if none.
Only calls within the same binary, plus calls from an overlay into
SLES_539.74, count as edges.

**callers.** The inverse of callees within this file: the funcs whose
callees list this func. Sorted, comma-separated; `-` if none.

**strings.** Collect every `.asciz` in `asm/<bin>/data/*.s`; lines look like
`    /* 2C1FC0 003C1FC0 */ .asciz "mg_draw.cpp"`; the second number is the
address. A function references a string when its body has `%lo(D_XXXXXXXX)`
or `%gp_rel(D_XXXXXXXX)` and `XXXXXXXX` is a string's address (src bodies:
any `D_XXXXXXXX` identifier). Write them in address order, joined with ` | `.
Escape tab, newline and `|` as `\t`, `\n`, `\|`, and cut each string to 60
characters. `-` if none.

**tu** (translation-unit guess):
1. If one of the function's strings ends in `.cpp` or `.c`, that file name
   (e.g. `mg_draw.cpp`). If there are several, take the first.
2. Otherwise, in address order within one binary: if the nearest function
   before it and the nearest after it that have a rule-1 name have the
   **same** name, use that name plus `?` (e.g. `mg_draw.cpp?`).
3. Otherwise `-`.

**Commit.** `tools/funcdb.py` alone, through the gate:
`funcdb: callers, callees, referenced strings, translation-unit guess`.

**Check (pass/fail).**
- The header ends `blocker	callers	callees	strings	tu`, and every row has 11 fields:
  `awk -F'\t' 'NF!=11' build/funcdb.tsv | wc -l` prints 0.
- `func_00145C30` (SLES_539.74, 320 bytes): `strings` starts with
  `mg_draw.cpp | texman | denv`, `tu` is `mg_draw.cpp`, and it has 2 callees.
- `func_0013B720` has at least 122 callers.
- SLES_539.74's data holds 6837 `.asciz` strings, 9 of them ending in
