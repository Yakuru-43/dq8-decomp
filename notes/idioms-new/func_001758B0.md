## Switch bodies via field pointers: assign `&obj->field` locals before the branch
Sign: a function whose case bodies (or a repeated block) store two adjacent
struct fields with `addiu $v1,$a1,4; ...; sw $r,0x0($v1)` / `addiu
$v0,$a1,8; sw $r,0x0($v0)` — materialized pointers, offset 0 — while the
same function elsewhere stores the same fields with `sw $r,0x4($a1)`. The
`addiu`s sit at the top of the function, one even in a `beqz` delay slot, and
the guard branches are plain `bltz`/`beqz` + `nop` (never `-l` forms with a
`daddu $vN,$zero,$zero` return-0 in the delay slot).
Fix: declare pointer locals and **assign them at the top, before any
branch**: `f4 = &arg1->f4; f8 = &arg1->f8;` and write the case bodies as
`*f4 = K;`. Declaring/assigning them inside the `else` block makes CW sink
the `addiu`s after the flag branch and merge the `return 0`s into branch-likely
delay slots; assigning them early keeps `$v0`/`$v1` live across the guards,
which blocks the delay-slot merging and restores the `bltz`/`nop` shape and
the register choices (the flag test falls to `$a2`). Pair with one shared
`if (a < 0 || a >= K) { return 0; }` so both guards target one stub.
