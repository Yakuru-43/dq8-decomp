## Index-clamp `||` whose second test sits in `$at`: write `count > i`, not `i < count`
Sign: a bounds clamp `if (i >= 0 || i < count) { e = &base[i]; } else { e = 0; }`
(binary-search entry fetch, 20-byte entries) where every word matches except the
second test's register: yours gives `slt $v0,$iX,$count` at the `bltzl` delay slot
and `bnez $v0,<addr>` in the cold clamp block, the original `slt $at` / `bnez $at`
(CLASS reorder+register, 2 words per clamp, size identical).
Fix: mh2 catalogue "Compare forms" first entry: MWCC computes a compare into a
**real register** only when it is `x < K` written as-is and branched true
(`x < K || ...`, `x >= K`, loop-bottom `while (i < n)`); `>` and `<=` everywhere go
to **`$at`**. So write the second test flipped: `if (i >= 0 || count > i)`, keeping
`i >= 0` as-is (`bltzl`). No temporary, no type change.
Also needed for the same function's tail: two guard clauses share one `return 0`
stub as `if (e != 0) { if (e->key == key) { return e; } } return 0;` (idioms.md
"one return stub means nested ifs" — the flat `if (e == 0) return 0; if (...)
return 0;` gives `beql`-to-jr and an inverted second test).
