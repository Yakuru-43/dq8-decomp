## Guard written as a positive `if (reg >= 0) { whole body }`, not an early return: CW puts the shared return stub at the `bgez` fall-through
Sign: a `void` function with a sign guard and one exit. The original is
`bgez $aX, <body+8>` with the return stub `b <epi>; <save-area load>` in the
fall-through right under the branch, and the body's tail ends
`b <that stub>; <last store in the delay slot>` (two returns share one stub).
Writing `if (arg0 < 0) { return; } ... body ...` gives `bltz $aX, <far epi>`,
the body falls into the epilogue, and the function is 8 B short
(CLASS structural, ~40 score; every later word shifted).
Fix: wrap the whole body in the positive test, `if (arg0 >= 0) { ...body... }`
— no early return. CW then branches forward on `bgez` to the body, lays the
empty else (return) as the stub at the fall-through, and merges the body's
tail into that same stub. Second trick in the same function: write struct
field stores **before** the call whose global argument loads above them
(`msg.a = 16; msg.b = 20; handle = f(D_g); g(&msg, handle);`) — CW hoists the
`lw` of `D_g` above the stores and sinks the last `sw` into the `jal`'s delay
slot; fetching the handle first puts the load in the delay slot and leaves
the stores after the call.
