# New idioms from func_00240020 (factory-2, 2026-11-05)

## Conditional RMW store through a materialised field address: assign `T *fp = &p->f;` BEFORE the load
Sign: a conditional `p->f = p->f / d;` whose original loads via the base register
(`lwc1 $f0,0x4($a2)`), materialises the store address separately (`addiu $a1,$a2,4`)
and stores through it (`swc1 $f0,0x0($a1)`), with the `addiu` scheduled between the
load and the op. Plain `p->f = q` folds everything to `4(base)` (no `addiu` at all);
`M2C_FIELD(p, f32 *, 4) = q;` folds too (the `(char *)p + 4` cast collapses to the
same offset); a pointer local assigned AFTER the load/div gets the pointer's own
register back (`addiu $a1,$a1,4`, wrong coloring in some blocks).
Fix: declare one `f32 *fp;` and write the address assignment BEFORE the read:
`fp = &p->hi; q = p->hi / d; if (o->mode == 3) { *fp = q; }` — with both `p` and `fp`
live at the load CW colours them `$a2`/`$a1`, the `addiu` lands between `lwc1` and
`div.s`, and every block matches. (For `Pair { f32 lo, hi; }`, `fp = &p->hi`.)
Example: src/SLES_539.74/func_00240020.c

## Union float-vs-cvt branch: write the INT path as the `== 0` arm to keep the float load in the taken branch's delay slot
Sign: `lw $v0,N(a); bnel $v0,$zero,<join>; lwc1 $f1,N+4(a)` then the fallthrough
`lwc1 $f0,N+4(a); cvt.s.w $f1,$f0` — the float read is a 1-word taken branch (load in
the delay slot, no `b`), the int read (load + cvt, 2 words) is the fallthrough.
Writing the natural `if (flag != 0) { d = u.f; } else { d = (f32)u.i; }` (or the
`?:` form) gives `beql` + an extra `b` and one word too many.
Fix: invert the test — `if (o->isFloat == 0) { d = (f32)o->div.i; } else { d = o->div.f; }`.
CW keeps the larger block inline and puts the small float read into the `bnel` delay
slot; the union { f32 f; s32 i; } is fine, the two loads are not CSE'd once the test
is right.
Example: src/SLES_539.74/func_00240020.c
