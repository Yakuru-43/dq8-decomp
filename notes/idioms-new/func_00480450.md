# Guard the raw call result: `if ((r = f(...)) == 0)` gives `beqz $v0` + the copy in the delay slot
Sign: after a `jal`, the original tests the **call result** (`beqz $v0,<ret1-block>`)
with `daddu $sN,$v0,$zero` in the delay slot, then uses `$sN` at every later site;
a plain `r = f(...); if (r == 0) return 1;` makes CW test the saved copy instead
(`daddu $sN,$v0; beql $sN,<ret1>; <ret-const>` — wrong regs, wrong opcode, often a
word off; CLASS structural).
Fix: write the assignment inside the condition:
`if ((r = func_16D5B0(arg0, arg1->field_4)) == 0) { return 1; }` — CW tests `$v0`
directly and keeps the `$sN` copy for the later uses. Same file, sibling trick: a
pointer only used for its null test, one arg and one post-call field read should
**not** need an `$s` register — `q = p + 8;` stays in `$a0` when the last read of
`q` is scheduled into the following `jal`'s delay slot (write `n = *(s32 *)(q + 4);`
on the line **before** `func_00479C50(q);`); keeping `q` live past the call forces
a spill and the guard flips to the `$s` form.
