pointer (`bltz` + `lw count` + `slt/beqz` + address math), where the standalone

`if ((i >= 0) && (i < M2C_FIELD(o, s32 *, N))) return o + ...; return NULL;`).

the blocks but not the schedule: CW steals the final `addiu` into the tail `b`'s
delay slot (no `nop`), points the guard-fail stubs at the join instead of the

break;`. Inlining the twin re-creates the twin's basic blocks, so CW lays the
tails, the `b tail; daddu v0,zero,zero` fail stubs and the join exactly right
(matched first try after the change).
