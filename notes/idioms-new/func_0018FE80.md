# Idioms-new

## Iterator loop as `while (1) { node = next(); if (node == 0) break; body }`: pre-test loop, not a bottom-test `bnel`
Sign: a loop whose head in the original is `jal <next>` (with `daddu $a0,$sN` in its
delay slot) then `beqz $v0, <end>` + `nop`, and the body's back-edges jump *back to the
`jal`*; `while ((node = func_XX_next(grp)) != 0) { ... }` instead rotates to a bottom-test
loop (call at the bottom, `bnel $v0,$zero,<top>` back-edge, `b` over it from the init) —
CLASS structural, the whole loop is laid out inverted and short by 2 instructions.
Fix: write the call as the first statement of a `while (1)` body and break on null:
```c
while (1) {
    node = func_001F2F90(grp);
    if (node == 0) {
        break;
    }
    ...body...
}
```
CW then keeps the call in the loop head, emits `beqz`+`nop` as the exit, and every
back-edge (including `beqz $s3,<top>` with a store in its delay slot) targets the call.
Common with the begin/next/end iterator triple `func_001F2FB0/func_001F2F90/func_001F2F80`
(this function has four such loops, all matching at once).
