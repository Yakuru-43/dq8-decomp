## `for` continuation condition, not `for (;;)` + `break`, for a 0-terminated scan

**Sign:** a fixed-length loop over an id/flag table that stops at the first
non-positive entry: `slti $at, $s0, 0x10` + `beqz` to the *single* exit, and
inside the body `lw` the table entry, `slt $at, $zero, $a0` + `beqz $at` to
that **same** exit label — no second `beqz` to a separate break block, no
`b` back-edge of its own for the test.

**Fix:** put the entry test in the `for` continuation, not the body:
```c
for (i = 0; i < 16 && 0 < D_003A5DB0[i]; i++) {
    ...body without the test...
}
```
`for (i = 0; i < 16; i++) { if (!(0 < D[i])) break; ... }` is wrong twice:
CodeWarrior emits `slti` + `beqz` for the bound, then a *second* test with
its own branch target, so the asm has two exit branches where the original
has one.

**Example:** `src/SLES_539.74/func_00220080.c`.
