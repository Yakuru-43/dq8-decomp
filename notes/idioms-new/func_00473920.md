# addu with the scaled index in `rs`: the byte offset in an int local of its own

Sign: register-only diff (CLASS reorder+register score=2), `addu` of `base + idx * 4`
where the original is `addu $v0,$v0,$sX` (the sll result in `rs`, base in `rt`) and yours
is `addu $v0,$sX,$v0`; every operand order and the `<< 2` / `* 4` spellings give base first.
The offset is used as a field (guard at 0x80, parallel arrays at 0x1D00+), not as the value.

`off = arg1 * 4; temp_v1 = (char *) (off + (s32) arg0);`
