# Idioms-new

## Kept `x = arg` copy feeding a later `addiu`: type the local differently, cast at the assignment
Sign: the original has `daddu $vN, $aM, $zero` (a copy of a parameter, often parked
in a branch delay slot) whose destination register stays live and is read by a later
`addiu $d, $vN, K`; your build emits the `daddu` (needed on another path) but
copy-propagates it into the `addiu`, which then reads `$aM` directly — CLASS
reorder+register, the whole block's roles rotate one register over (temp taken from
a freed arg register, header instruction order shifted).
Fix: give the copy-target local a different integer type than the parameter and cast
at the assignment: `u32 end; ... end = (u32)arg0;` (MH2 Saved, "The game keeps a
separate copy of a value that yours folds away"). Read it back through a cast where
signedness matters (`base = (s32)end + 4;`, `return ((s32)end - arg0) / 4;` — an
un-cast u32 subtraction folds the signed `/4` bgez/sra pattern into srl). One cast
fixed all 10 diff words at once.
