## Indexed setter with `bltz` + `slti $at/beqz` into one epilogue: two positive nested ifs
Sign: bounds-check + indexed call, asm is `bltz $a1, <epi>` / `slti $at, $a1, N` /
`beqz $at, <epi>` / `nop` / body **inline** / fall into one `ld $ra; jr $ra` epilogue
(second test uses `$at`, no named temp, no `bnez`). Writing the second test as an
early return (`if (idx >= N) return;`) makes CW invert it to `slti $v1; bnez $v1,
<body-out-of-line>` + `b <epi>; <dup epilogue>` before the body (mine 84 vs 76 B,
CLASS structural); a top-level positive `if (idx < N) { call; }` after an early-return
first guard does the same inversion.
Fix: write both tests positive and nested, no returns:
`if (idx >= 0) { if (idx < N) { func(base + idx * 608, value); } }` — `idx >= 0`
gives the plain `bltz` (SKILL.md "Constant on the left"), the nested positive test
gives `slti $at` + `beqz` to the shared epilogue with the body inline. Constant
multiply `idx * 608` folds to the `sll/addu` chain (x9, x2+1, <<5) on its own.
