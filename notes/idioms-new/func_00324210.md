## A local that must sit in `$a1`: pass it as an extra arg to the debug printf
Sign: CLASS reorder+register, score ~3, everything word-identical except one
local: your `addiu $vN,$v0,1` / `slti $vM,$vN,K` / `sw $vN,D_x($gp)` triplet is
in `$v1` where the original has `$a1` — and the function calls a debug print
(`DebugPrintf`/`DebugPrintf2`) on the fall-through path, with the store sitting
between the test and that `jal` (the arg registers are all "free" on paper).
Fix: pass the local as an additional argument to the debug call:
`DebugPrintf2(&msg, n);` (declare it variadic: `M2C_UNK DebugPrintf2(M2C_UNK *, ...);`).
CW then colors the value into the argument register `$a1` for the call, which
ripples back so the `addiu`/`slti`/`sw` all use `$a1`; the delay slot of the
store stays free. Nothing else about the call changes — a debug print taking
the counter it just guarded is also natural code.
