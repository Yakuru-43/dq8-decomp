## Sentinel compare on a `char *` string: read the tested byte into an `s8` local
Sign: the original has `lb v0,N(ptr)` in the loop test, `dsll32 v0,v0,24` in the branch's
delay slot, and `dsra32 v0,v0,24` at the top of the body before a `bne v0,v0const` against
a constant (e.g. `-` / 0x2D), while a *second* byte of the same string is compared with a
plain `beq/bne` and no shifts. Drafting the compare as `*p == '-'` (with `char *` or even
`s8 *`) emits no `dsll32/dsra32` at all, so every later word shifts (mine 200 vs 212 B,
CLASS structural).
Fix: declare the loop's tested byte as a plain `s8` local and write
`while ((c = *s) != 0) { if (c == '-' && *(s + 1) == '-') { break; } ... }` — the `s8`
assignment gives the sign-extend pair on the sentinel compare, the `char *` deref of the
neighbour byte stays shift-free, and the final raw `lb`/`lb` `bnel` compare loop stays
shift-free too. Keep the neighbour byte and the compared byte as *different* expressions.
