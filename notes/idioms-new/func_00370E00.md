## `x = x + y` vs `x += y` on a `s16` member flips the `addu` register allocation
Sign: a halfword RMW block is otherwise identical to the original but the two
`addu`-block words differ only in register choice: the original has the field
load in the `addu` destination register (`lh $v0,N($s0); ... dsll32/dsra32 $v1
for the arg; addu $v0,$v0,$v1`) while mine has field/arg swapped
(`lh $v1,N($s0); dsll32 $v0...; addu $v0,$v1,$v0`). The `-` sibling block
(`subu`) matches; only the `+` blocks differ.
Fix: write the statement as `+=` instead of `x = x + y` (and vice versa).
Same value, different CodeWarrior temp order. Here `stats->unk_12 += (s16)arg1;`
flipped both `+` blocks to the original's registers in one edit; the explicit
`x = x + y` form was the one that mismatched.
