## Arg value used as a pointer: `s32 *p` member on the per-file Value union
Sign: tagged-arg function where a tag arm uses the arg's value as an address:
`beql $v1, $v0(3), L; lw $vN, 0xC($a0)` (the pointer loads only in the taken
delay slot), then in the cold block `b <ret>; sw $aM, 4($vN)`.
Fix: add `s32 *p;` to this file's `union Value` (each file in this TU defines
its own) and write `args[k].value.p[1] = val;` — the `+ 4` folds into the
store offset and the load of `.p` stays in the branch delay slot. With only
`s32 i` + a cast, CW tends to materialize the add or keep the value in a
differently-coloured register.
