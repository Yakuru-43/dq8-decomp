## The same `beqz $vN` tested 2-3 times in a row: repeated `if (x == 0) { }` statements, no else
Sign: after a matched prefix, the original re-tests the same condition with plain
`beqz` + `nop` at several merge points (`beqz v1,+A; beqz v1,+B; beqz v1,+C`)
and the cold arms `b` **back into** the next test; mine has the tests folded
into fewer branches and is 8-32 bytes short.
Fix: write each test as its own `if (x == 0) { ... }` statement in sequence —
no `else`, no `else if`. With `else`, CW proves the negation on the arm's edge
and deletes the re-test (and routes the cold arm past the shared store); with
separate statements both arms fall into the following test block, which has to
stay. Positive/negative spelling of each `if` decides which arm is the cold
copy.
