## Shared fail stub with `goto` + materialized `!(x) != 0` first guard

**Sign:** a guard chain where several arms assign the same local to 0 (e.g.
`entry = 0` for a bad key, a bad index and a stamp mismatch) before one
`if (entry != 0) { body }`. The orig merges all but the first fail arm into
ONE cold block `b <merge>; daddu $v1,$zero,$zero` (two guards' branches point
at the same stub) and the success path falls straight into the merge; a plain
nested if/else chain instead zero-assigns inline near the last guard and adds
a `b <merge>` after the success (CLASS structural, ~4 words off, all at the
top). Also: the first test reads `lw $v1,slot; sltu $v1,$zero,$v1;
xori $v1,1; bnez <stub>` with the `daddu $s0,$a0,$zero` copy in the `bnez`
delay slot — the negated compare is materialized as a value.

**Fix:** two things. (1) First guard: `if (!(IsValid(key)) != 0) { entry = 0;
goto merged; }` where `static inline s32 IsValid(Stamp key) { return key.word
!= 0; }` — plain `!IsValid(key)` folds to `beqz` (see MH2 §2162, "computed
`!x`"). The `!= 0` forces the sltu/xori/bnez. (2) Write the rest as gotos, not
nested ifs, so both fail arms name the SAME label and the success arms name
the merge label:
```c
    key = stamp;
    if (!(IsValid(key)) != 0) { entry = 0; goto merged; }
    index = key.half[0];
    if (!(index < list->count)) { goto none; }
    elem = At(list->array, index);
    if (elem != key.half[1]) { goto none; }
    entry = &list->entries[index];
    goto merged;
none:
    entry = 0;
merged:
    if (entry != 0) { ...body... }
```
MWCC then emits one cold stub shared by the two `goto none` branches, keeps
the first guard's own stub (its `entry = 0` is a distinct statement), and lets
success fall into the merge — 200/200 bytes. A by-value union copy at the top
(`Stamp key; ... key = stamp;`, locals declared `found, key, hint, index,
elem, entry`) comes for free as `sw $a1,0x20(sp); lwc1; sd $ra; sq $s0;
swc1 $f0,0x28(sp)`.
