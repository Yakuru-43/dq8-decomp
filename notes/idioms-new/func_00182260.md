## A `!= K` guard becomes `beql` + swapped arms; write `== K` to get the original's `bnel`
Sign: a guard-chain tail that compares an `s16` global against a nonzero
constant K: `addiu $v0,$zero,K; bnel $v1,$v0,<epi>; lw $v0,A` then
`b <epi>; lw $v0,B` (the != K path is the branch, its return value in the
delay slot; the == K path falls through a private `b` stub). Writing
`if (g != K) { return A; } return B;` gives CW the inverted `beql $v1,$v0`
into the same layout with the two `lw`s swapped (CLASS structural, score 1,
every word present — only the branch opcode differs).
Fix: flip the source test and swap the returns:
`if (g == K) { return B; } return A;` — CW then emits the plain `bnel` with
A in its delay slot and the `b epi; lw B` stub for the == path. Compare
against 0 in the same shape keeps the ordinary `if (f() != 0) return X;`
guard (it emits `beqz`/`beql` + nop directly).
