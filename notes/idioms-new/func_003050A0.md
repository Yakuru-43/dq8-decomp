## `addu` index-first: the base needs a typed-pointer local, not a cast in the expression
Sign: register-only diff, one word: original `addu $v1,$v0,$s0` (scaled index term in
`rs`), yours `addu $v1,$s0,$v0` (base first), at `base + (idx << 1)` feeding an
`s16`/`s32` load with the constant folded into the offset. Reordering the `+` operands
in C does nothing; the "byte offset from the array member" fix ((idioms.md, addu in
rs)) was tried as `((S_tbl *)tbl)->slots[idx]` over an `s32 tbl` and still emitted
base-first.
Fix: declare the **local** with the struct pointer type (`S_tbl *tbl; ...
tbl = (S_tbl *)func_00305240(obj);`) and subscript the array member plainly
(`val = tbl->slots[idx]; ... tbl->slots[idx] = val;`). With the typed local CW
colours the index term into `rs`; with `s32` + a cast per expression it does not.
