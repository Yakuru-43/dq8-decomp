## Left-aligned byte return tail: `if (ret < 0) return -1; return (u8)ret << 24;`

Sign: a function whose arms all assign one shared local constants (`ret = K;`) with a
single conversion block before the epilogue:
`bgezl $v0,+2; andi $v0,$v0,0xFF / b epi; addiu $v0,$zero,-0x1 / sll $v0,$v0,24`,
and every arm reaches it as `b <conv>; addiu $v0,$zero,K` (the constant rides the
branch's delay slot). Callers test the result with `bltzl` and pass it on unchanged.

Fix: write the tail exactly like that in C — a plain `s32` local, every arm assigns,
then
```c
if (ret < 0) {
    return -1;
}
return (u8)ret << 24;
```
CW emits the whole shared tail itself; do not hand-mask. Related gotcha (same match):
if the last `else if`'s arm polarity is inverted (`beql`+delay-slot constant where the
original is `bnel`, original `b`-arm falls through to the other constant), swap the two
arms — CW keeps the *then* body inline and puts the else value in the jump.
