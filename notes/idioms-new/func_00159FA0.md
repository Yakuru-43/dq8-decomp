## Branchless `K`-or-0 select from a call result: write `f(...) == 0 ? K : 0`, the flipped form preloads 0 and adds a word
Sign: a tail `addiu $v1,$zero,K; movn $v1,$zero,$v0; daddu $v0,$v1,$zero`
(no branch) after the last `jal` of a guard chain: the result is K when the
call returned 0, else 0. Writing the same select as `f(...) != 0 ? 0 : K`
makes CW pre-load the 0 arm first: `daddu $a0,$zero,$zero; addiu $v1,$zero,K;
movz $a0,$v1,$v0; daddu $v0,$a0,$zero` — 4 words, one too many, and the
select lands in `$a0` (CLASS structural, 180 vs 176).
Fix: write the **equality** form with K on the true side:
`return func_00130F38(obj, D_003C20A8, 3) == 0 ? 3 : 0;` — CW then preloads
the K value and zeroes it with `movn`, no extra register. Related to
func_001C57D0's "write the ternary, not if/else": same rule, and here the
condition sense picks the lowering.
