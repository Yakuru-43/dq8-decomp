## Loop arm's exit `b` merges into the else arm's tail block: put `return;` in the else
Sign: an `if (x < 0) { i = 0; do { helper(i); } while (++i < N); } else { helper(x); }`
where everything matches except one word (CLASS reorder+register, score 1): the loop's
exit `b <epilogue>` instead points at the `b <epilogue>` instruction that ends the
else arm's inlined helper (a `b`-to-`b` hop). Both arms otherwise sit in the right
blocks. Seen in the indexed-getter family (`src/SLES_539.74/func_0016B2F0.c` style).
Fix: write the else arm as `else { helper(arg); return; }`. The explicit `return;`
gives the else arm its own tail block, so CW stops merging the loop exit into it and
emits a dedicated `b <epilogue>; nop` after the loop (matched on the try after the
change, 188 bytes; the plain `else { helper(arg); }` was score 1 forever).
