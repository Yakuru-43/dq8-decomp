## Tag test folded to the base, both value loads via one materialized pointer local
Sign: a tagged select `if (tag == 0) { v = (f32)i; } else { v = f; }` where the sibling
selects in the same function come out `bnel` + the float `lwc1` in the delay slot, but the
original of **this** one is `lw $v0,N($a0)` (tag, folded onto the arg base), `bnez $v0,<float>`
(plain, not likely) with `addiu $v1,$a0,N` in its delay slot, the int arm inline
(`lwc1 $f0,4($v1); b <join>; cvt.s.w`), and the float arm out of line as a lone
`lwc1 $fN,4($v1)`. Mine uniform: all selects give `bnel` + delay-slot load, 8 B short per
materialized block (CLASS structural, score ~17).
Fix: keep the tag test written **directly through the arg** (`*(s32 *)(arg0 + 8) == 0`) but
read both values through a `Val *` local assigned on the line just above (`y = (Val *)(arg0 + 8);`
then `(f32)y->v.i` / `y->v.f`). CW then CSEs only the value loads onto the shared base
(`addiu` scheduled into the branch delay slot, both arms `4($v1)`) and inverts to a plain
`bnez`; the uniform spelling (tag also via byte offsets, no local) folds both value loads
to `N+4($a0)` and gives no `addiu`. The other selects stay byte-offset C.
