## Per-iteration field load in the back-edge delay slot: read the member directly, never through a hoisted local
Sign: the original loop entry is `lw count,4(a0); daddu v0,zero,zero; b <test>;
daddu i,zero,zero` (i in the branch delay slot, no entry trip guard) and the back
edge is `slt vN,i,count; bnel vN,zero,<body>; lw aX,8(a0)` — the field load runs
every iteration in the back-edge delay slot. Writing `base = tbl->low;` as a local
(before the loop or as the body's first statement) gets it hoisted: the load lands
in the entry `b`'s delay slot, the back edge becomes plain `bnez` + `nop`, and CW
adds an entry guard `slt $at,$zero,count; beqz <exit>` (184 vs 168 B, CLASS
structural score ~47, whole register cluster shifts: count $t1, i $t2).
Fix: no local — reference `tbl->low` directly at both uses:
`if (tbl->low != 0 && i >= 0 && i < count) { if (i < 32) node = tbl->low + i * 0x220;
else node = tbl->high + (i - 32) * 0x220; } else node = 0;`. CW then CSEs the two
loads within one iteration, schedules it as the body's first instruction into the
back-edge delay slot, lays the entry `b` with `daddu i,0` in its delay slot, drops
the entry guard, and the `i < 32` if/else becomes `beql` + `lw $v1,0x10($a0)` in
the delay slot. Pair it with the shared-tail shape of
notes/idioms-new/func_003397F0.md for the guard/else/tail layout.
