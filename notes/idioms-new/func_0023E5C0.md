# Idioms-new

## Tagged union getter: if/else statement for the pair, flipped ternary for the singleton
Sign: a tagged union `{s32 type; union {s32 i; f32 f;} v;}` read into a float local.
Three loads of the same `0x4(base)` word, one `cvt.s.w`, but the block shape varies:
a separate float block behind a plain `bnez` with `addiu reg, base, 8` in the delay slot
and `cvt.s.w` in a `b`'s delay slot; or a `bnel`-to-join with the `lwc1` in its delay slot
and a duplicate `lwc1`+`cvt.s.w` on the fall-through.
Fix: for the `bnez` form write the pair as an `if/else` **statement** with a named `f32`
local and a separate store (`if (t->type == 0) { fx = (f32)t->v.i; } else { fx = t->v.f; }
vec[0] = fx;`); for the `bnel`-to-join form use the **flipped** ternary through that local
(`fz = tx[2].type == 0 ? (f32)tx[2].v.i : tx[2].v.f;`). The non-flipped ternary (`!= 0 ? f : (f32)i`)
makes CodeWarrior fuse the pair into a 6-word block and shifts the tail. Also: the base
register must be derived from a running pointer local (`tx = &p->x; ty = tx + 1;`) so the
`addiu reg, prev, 8` lands in the delay slot rather than `&p->y`; subscript the singleton
off the same pointer (`tx[2]`), never `&p->z`.
