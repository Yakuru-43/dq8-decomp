# Idioms-new

## Cold `call; return;` early exits hoisted before the join: write them as goto labels after the tail
Sign: a function with a hot tail (e.g. a float divide + call) reached from most
paths, plus 1-2 early exits `if (x == 0) { f(a, 0); return; }` whose asm the
original lays out AFTER the tail block, sharing one `ld $ra` stub; your
`if { call; return; }` version puts the second exit's cold copy BEFORE the join
and shoves the join's small then-arm out of line (CLASS structural, +4-8 B and
everything shifts; flipping tests, nesting under positive tests and the
"Small then-block placed cold" entry do not move it).
Fix: write the exits as explicit gotos to labels placed after the tail:
`if (v == 0) { goto fail0; } ... tail(); return;` then `fail1: f(a,0); return;`
then `fail0: f(a,0); return;` (label order = original block order: the
mid-function exit's label first so its block lands first, the guard's falls
into the shared `ld $ra`). CW keeps explicit goto blocks where they are
written; `goto` precedent: notes/idioms.md "Free-slot search".

## `&D_` of a far .data global as `lui`/`addiu %hi/%lo` where yours is one gp-relative `addiu`
Sign: passing `&D_XXXXXXXX` to a call; the original is `lui $a0,%hi(D_..)` +
`addiu $a0,%lo(D_..)` (2 words, one possibly in a delay slot), yours is a
single `addiu $a0,$gp,K` (CLASS reorder+register at the size level but 4 B
short overall). The same symbol referenced by LOAD (`lw $v1,K($gp)`) is fine
plain — only address-of differs.
Fix: declare it `extern M2C_UNK D_XXXXXXXX __attribute__((section(".data")));`
(the attribute keeps it out of small data, so `&` costs hi/lo). Plain
`extern s32 D_...;` stays correct for gp-relative loads. Precedent in src:
func_00310390.c.
