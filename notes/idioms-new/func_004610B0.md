## Call arg equal to a just-stored stack byte: pass the *global*, not `buf[0]`, to keep `$a2` alive
Sign: three `lbu` of consecutive `.sdata` bytes into `$a2/$a0/$v1`, three `sb` into a
stack buffer (0x4C/4D/4E($sp)), then `lb $a0,0x4C($v0)` with `addu $v0,$s2,$sp` (a stack
`s8 buf[4]` indexed by an s32 parameter) and a call whose **third** arg is the same value
as `buf[0]`. Drafting the arg as `buf[0]` emits a reload `lb $a2,0x4C($sp)` (+4 B, CLASS
structural, score 15 — and it also flips the earlier guard `beqz` into `beqzl` because
the block gets longer); drafting it as the global reuses the live `$a2`, no reload.
Fix: load through `u8 D_003E0148[] __attribute__((section(".sdata")))`, store
`buf[i] = D_x[i];` (batched loads before stores, idioms-new func_004607A0 style), declare
the buffer `s8 buf[4]` (the indexed read is `lb`, sign-extend) and write the call arg as
the **global subscript** `D_x[0]`, not `buf[0]` — CW CSEs the two loads into the single
early `lbu $a2` whose register survives to the call. With the right size the guard comes
out plain `beqz` + `daddu $s0,$a1,$zero` delay slot on its own.
Overlay `.sdata` externs also need `D_003E0148 = 0x003E0148;` — `tools/keep_funcs.py`
records it when a build needs it; the file `config/symbol_addrs_<bin>_local.txt` is not
editable from a factory session.
