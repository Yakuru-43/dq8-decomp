## `mflo`+`mult`+`subu` for `%` vs bare `mfhi`: write the quotient, not the modulo
Sign: after a guarded `div $zero, $a, $b` (`bnez` + `break 0, 7`, divbyzerocheck flag),
the original computes the remainder as `mflo $v1; mult $v0, $v1, $v0; subu $s2, $s2, $v0`
instead of a plain `mfhi` — and/or returns/uses `mflo` directly where C would say `%`.
A C `%` always compiles to `mfhi` (even with a variable divisor), so `%` never gives
this shape.
Fix: write the manual form with the quotient in its own local:
```c
q = acc / r;            /* div (guarded), mflo q */
acc = acc - q * r;      /* mult, subu */
```
and use `/` (not `%`) where the original ends on `mflo`. Mixing is common in one
function: `% 10` (constant) stays `div`+`mfhi`, the variable-divisor one is the
quotient form.
