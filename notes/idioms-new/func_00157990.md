## Bitfield store equal to the case's constant: write the literal, CW reuses the compare chain's register
Sign: a `switch` whose case bodies store into a narrow bitfield (`u8 mode : 2`); mine emits
`andi $vN,$a1,0x3; sll` (source = the switch argument register) where the original has
`andi $v1,$v1,0x3` — the andi's source is the register the compare chain loaded the *case
constant* into. CLASS register-only, score 2, everything else word-identical.
Fix: write the case value as the literal (`case 2: o->flags.mode = 2;`), not `= mode`: CW
reuses the constant its compare chain left in `$v1` rather than re-reading the argument (mh2
catalogue, Temporaries, "v0 and v1 (or a0-a3) swapped around a switch"). A case reached from
two tests (e.g. `case 0: case 1:` storing 1) has no single-edge equality and folds to a plain
`daddiu $r,$zero,1<<pos` instead — that is correct, don't fight it.
