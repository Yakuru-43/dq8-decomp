## Two-store 0/1 toggle: `bnel + store-0 in delay slot + li/sw 1 inline`
Sign: `bnel $v0,$zero,+3` with `sw $zero,N($s0)` in the delay slot, then `addiu $v0,$zero,1;
sw $v0,N($s0)` inline, then a reload `lw $v1,N($s0)` feeding the next use. `if (v) {f=0;} else
{f=1;}` gives CW's `beql; li 1; b; nop; sw 0; sw v0` (4 words too long); `f=0; if (v==0) f=1;`
places the store-1 arm cold at the tail with a `b` back.
Fix: write the arms with the **1-store first**: `if (v == 0) { obj[0xAF3] = 1; } else {
obj[0xAF3] = 0; }` — CW then branches over the then body with `bnel` and drops the else's
store-0 into the delay slot, then body inline, value reloaded by the next expression.
Same function's tail: two separate `return -1;` statements get two `b epi; li -1` stubs; write
one `if (f(A,m1) != 0 || (f(A,m2) != 0 && obj[0xAF3] == 1)) { return -1; } return 0;` so the
single `return -1` becomes one stub shared by a backward `beq`, and `return 0` falls into the
epilogue. Related to idioms.md "Two `return 0` share one stub".
