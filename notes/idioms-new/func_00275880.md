## `if (x == 0xFFFFFFFF)` as `> 0xFFFFFFFE`: sltiu $at + bnez instead of a materialized -1
Sign: the original guards with `lw $v0,N(a)` (or any load) then `sltiu $at,
$v0, -1; bnez $at, skip` (2 words) around a warn block. `== 0xFFFFFFFF`,
`== -1`, `>= 0xFFFFFFFF`, `!= 0xFFFFFFFF` and `!(x < 0xFFFFFFFF)` all make
CW materialize the constant (`addiu $vN,$zero,-1` + `bne`, 3 words) and
schedule it into the prologue, shifting the whole function.
Fix: write it as `if (x > 0xFFFFFFFE) { body; }` — MH2 "Compare forms" says
`<`/`>` in a plain if compute into `at` (the bltu macro), `>=` in an if
computes into v0. Unsigned field (`u32`) and the plain constant, no `U`
suffix needed.
Example: src/SLES_539.74/func_00275880.c, head guard on `owner->field00`.
