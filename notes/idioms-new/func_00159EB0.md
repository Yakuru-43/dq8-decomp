## Two back-to-back `beql`s on the same arg register: an early-return guard plus a chain arm that rechecks it
Sign: the prologue saves `arg0` (`daddu $s0,$a0,$zero`) then tests it twice
in a row: `beql $s0,$zero,<jr stub>; daddu $v0,$zero,$zero` and
`beql $s0,$zero,<tail>; daddu $v1,$zero,$zero` — the first returns 0, the
second jumps to the shared tail carrying a kind/flag local set to 0. Notes
call the second one "a redundant null check"; deleting it makes the function
4-8 B short (CLASS structural).
Fix: CW does not eliminate a recheck of a pointer already early-returned
on. Write both: `if (obj == 0) { return 0; }` first, then an if/else-if
chain whose **first arm** is `if (obj == 0) { kind = 0; }` — CW emits the
second `beql` into the tail jump with the 0 store in its delay slot. The
tail is then `if (kind == 0) { return 0; } ...`.
Also in this function: the two-test range check `if ((u32)(kind - 1) <= 1)`
emits `addiu -1; sltiu $at,2; bnel $at` — write `<= 1`, not `< 2` (computed
values with `<=`/`>` go to `$at`, per func_00338080's mh2 compare-forms note).
