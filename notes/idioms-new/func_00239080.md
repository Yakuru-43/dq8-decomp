## Empty `while (1) {}` after a DebugPrintf: 5x nop + `b` back to the first nop + nop
Sign: a debug-error block `lui $a0,%hi(str); jal DebugPrintf; addiu $a0,%lo(str)`
followed immediately by a 7-word dead block `nop; nop; nop; nop; nop; b <first nop>; nop`
(the branch targets the nop right after the jal's delay slot, so the whole block is an
empty spin). Notes call it a "nop spin" / "terminate island"; the throw() entry in
idioms.md is a different producer (there the spin follows `jal func_00101510`).
Fix: write it as plain C after the print: `DebugPrintf(...); while (1) {}` (empty body,
no volatile, no counter). At `-O3` mwccps2 emits exactly that 7-word block in one
attempt. Do not try `for (;;)` variants or volatile reads first.

## Duplicate-scan over a fixed record table: `for (k = 0; k < j; k++)` with the non-returning arm
Sign: an outer `for (j = 0;; j++)` over 8-byte records, an inner scan over the PREVIOUS
records whose hit arm prints and spins (never returns): the asm is `b <test>; daddu $t1,
$zero,$zero` entry, body `lw $v1,4($a3)` (cur field), `addu $a0,$t0,$a0` (record base +
scaled index, the `sll $a0,$t1,3` sitting in the back-edge `bnel` delay slot), `lw $a1,
4($a0)`, plain `beq` to the cold print block with `nop` delay slot, then `addiu $t1,$t1,1`.
Fix: write the scan as `for (k = 0; k < j; k++) { if (cur->f == TABLE[k].f) { DebugPrintf(
str, TABLE[k].f); while (1) {} } }` — pass the print argument as the **right operand of
the `==`** so its already-loaded value (in `$a1`) is reused with no move; the beq stays
plain (not beql) because the arm never falls through. The record base `lui/addiu %hi/%lo`
recomputed at each outer iteration came for free from writing `e = &TABLE[j];` inside the
outer loop body.
