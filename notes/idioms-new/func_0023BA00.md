## Tagged-union slot reads: an `Arg *` local per slot, value in one join temp

**Sign:** a run of `(tag == 0) ? (f32)i : f` slot reads over a `struct { s32 tag;
union { s32 i; f32 f; } value; }` array, where the original materializes
`lw $v1,K($a0); bnez $v1,+4; addiu $a2,$a0,K; lwc1 $f0,4($a2); b; cvt.s.w |
lwc1 $f0,4($a2)` — one store per slot, placed **after the next slot's tag
`lw`**. Writing `args[k].value.i` / `.f` (or a `Value *vp = &args[k].value`)
folds it wrong twice: the `addiu` swallows the `+4` (`addiu $a2,$a0,K+4;
lwc1 $f0,0($a2)`) and the member store is duplicated into both arms instead of
shared after the join (CLASS structural, one word short per slot).

**Fix:** keep a typed base local per slot and funnel both arms through **one**
`f32 val;` temp, with the member store *after* the if/else:
```c
ap = &args[1];                 /* Arg *ap;  (NOT Value *vp = &args[1].value) */
if (args[1].tag == 0) {
    val = (f32)ap->value.i;
} else {
    val = ap->value.f;
}
vec.v.x = val;
```
The typed `Arg *` keeps the `addiu` at the Arg base with `4($a2)` on the load;
the shared temp makes CW merge the arms into one `$f0` and emit a single `swc1`
after the join, which the scheduler then slides after the next tag's `lw`.
