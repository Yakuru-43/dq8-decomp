## Range guard with duplicated `slti $at,r,0x0` + shared `bnez`: write `-1 < n`
Sign: a select if/else (int/float read at +4) feeding a range guard; the original
computes `n < 0` into `$at` in **both** arms (float arm: in the `b` delay slot; int
arm: after the `lw`) and tests once after the join: `bnez $at, <cold>; nop`, then
`slti $at,n,4; beqz $at, <cold>; nop`, body inline, cold block last. Plain
`if (n >= 0 && n < 4)` / `if (!(n < 0) && n < 4)` fuse the first test to one
`bltz`+`nop` at the join (1 word short, everything after shifts, CLASS structural).
`0 <= n` (idioms.md "Constant on the left") *does* duplicate the test into both
arms — but emits `slt $at,$s1,$zero` (op 0x1A), wrong encoding vs `slti` (op 0x0A).
Fix: `if (-1 < n && n < 4) { body } else { cold }` — the left-constant `-1 < n`
keeps the compare unfused into `$at` **and** CW emits `slti $at,$s1,0x0`; the
scheduler then hoists/duplicates the `slti` into both select arms (delay slot of
the float arm's `b` + after the int arm's `lw`) for free. Second operand stays
plain `n < 4`. Matched on the 4th try.
