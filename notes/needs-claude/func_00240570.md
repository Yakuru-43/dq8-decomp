if `y < 0` stores `v` at `o->cells->vals[idx]` (`lw a0,0x1930(a0)` **in the
`bltzl` delay slot only** — annulled on the fall-through, so `cells` is read
on that arm alone); else guards `0 <= x < 0xC0`, `0 <= y < 8`, loads the
entry pointer at `o + 0x130 + x*0x20 + y*4`, null-checks it, stores `v` at
`->vals[idx]`; returns 1, or 0 on any guard/null. `vals` is the `f32` array
at member offset 0x114 (typed member array fixed the store's `addu` operand
order per notes/idioms-new/func_0023F360.md).
