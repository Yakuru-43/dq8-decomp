# func_00104A00 — Reader buffer drain with 0xFF terminator

- size: 1008 B, range 0x104A00 0x104DF0, `asm/SLES_539.74/text_104A00.s`
- Neighbours `func_001046C0`/`func_00104780` matched (same Reader struct);

## What it does
`func_00104A00(Reader *reader /*s1*/, s32 byte /*s0*/)`, frame 0x60, saves
ra@0x40, s3,s2,s1,s0. Returns s32.

- `reader->field_1C == 0` → -1 (out-of-line at 0x104BE4, delay `daddu s0,a1`).
- If `field_36 != 0 && field_14 == 0` (plain `beqz`+nop, `bnez`+nop on the
  `lbu`/`lw`): if `(u32)field_08 < (u32)field_0C` (`sltu`+`bnel`, `lw $t9,0(s1)`
  in its delay slot) call the two-level indirect `lw t9,0(s1); lw t9,0x10(t9);
  jalr` with `a0=&out` (u64 at sp+0x50), `a1=reader, a2=0, a3=2`; `ld v1,out;
  bne v1,-1` → 0x104A54, fall through → `return <call result in v0>`. 0x104A54
  (shared with the `08 >= 0C` fall-through): `field_14 = &reader+0x24;
  field_10 = &reader+0x24;` then delay slot of `b C24`: `field_18 = &reader+0x34`
  (the 16-byte inline buffer at 0x24).
- `field_34 = 1;` (`addiu v0,1; sb v0,0x34`). `beql v0(=lbu field_35), zero,
  B80` delay `lw s2,0x10(s1)`; fall-through `b A6C` delay `lw s3,0x10(s1)`.
- **Main loop** (s3 u32 cursor, entry `sltu at`+`beqz AF4`, bottom `sltu`+`bnez
  A7C` — while form): per byte `s2 = lb 0(s3)` (s8), push to stream
  (`field_1C`) via an inlined char-push helper (see below), then live test
  `andi v1, s2, 0xFF` vs `-1` (`bnel v1,-1 → AE4`): equal → erase prefix
  (`func_00130FD0(field_10 /*dst*/, cursor, field_14 - cursor)`, guarded by
  `sltu a0, at, s3`+`bnel` on `field_10 < cursor`) and
  `field_14 += field_10 - cursor`, `return -1`. AE4: `s3++`, re-test.
- **Char-push helper** (inlined 2x here, also visible in `func_00106250`
  loop @0x106294, itself still todo): `left = st->08 - 1; st->08 = left`
  (`lw`+`addiu`+`bltz` with the `sw` in the delay slot, so the store happens
  on the error path too); if `left < 0` → error block; else
  `*(s8*)st->00 = ch` (via reloads of `field_1C`!), `v1 = st->00;
  st->00 = v1+1; v0 = lbu(v1)` read-back; then a DEAD
  `addiu v1, zero, -1; bnel v0, v1, <next>` whose target equals its
  fall-through (delay `andi v1, s2, 0xFF`), i.e. an `== -1` compare CW kept
  because it cannot range-propagate the `lbu`. Success = loop continue.
- **Error block** (0x104C40/0x104CD0, one per call site, mirror of 106250's
  0x1062F0): `if (st->08 < st->18)` (`slt`+`bnel`, delay `dsll32 a0,s2,24`) →
  `func_00138828((s8)ch)`; else `*(s8*)st->00 = ch`, read-back
  `beq v0, a0(=10, addiu a0,zero,0xA before the store)` → `jal func_00138828`
  (a0 = 10 survives as its argument), else `st->00++` with read-back; all arms
  rejoin at the dead `bnel` (@0x104AB8 / @0x104B60) → loop continue. The
  `addiu v1,-1` in the rejoin delay slots is overwritten by the `andi` — dead.
- **Tail** (AF4): `field_14 = field_14 + (field_10 - field_14)` (= field_10,
  stored in the delay slot of the append test). Append guard is the C++
  bool-vs-false idiom: `not v0,s0; sltiu v0,1; xori v0,1; andi a2,0xFF;
  beqz a2 → B70` = `if ((byte != -1) != false)`. Append body: `s2 = (s8)byte`
  (`dsll32/dsra32 24`), same push helper, then `not v0, v1(=s2&0xFF);
  sltiu a2, v0, 1` (= (v1 == -1)); `B70: beqz a2 → BCC` (raw encoding
  `1600C010`, imm 0x16 — **target is 0x104BCC**, spimdisasm prints a wrong
  label) else fall → `return -1`.
- **B80 path** (field_35 == 0, s2 = field_10 cursor): loop while
  `(u32)s2 < field_14`: `func_00106250(reader, 1, *(s8*)s2)` — on -1 erase
  (same memmove+shrink @0x104D88) and `return -1`, else `s2++`. Then B94:
  `field_14 = field_10` (in the delay slot of `bnez v0 → DAC`, v0 =
  `not/sltiu/xori` = byte != -1), `s2 = 0`; DAC:
  `func_00106250(reader, 1, (s8)byte)`, `s2 = (rc == -1)` (`bne v0,-1 → BBC`
  / fall `daddiu s2,1`); BBC: `beqz s2 → BCC` else `return -1`.
- **BCC** (shared tail): `if (byte == -1) byte = 0; return byte;`
  (`addiu v0,-1; bne s0,v0,BDC; s0=0; BDC: b DD4; daddu v0,s0`).

## Why it needs Claude
- The dead `== -1` compares + dead `addiu v1,-1` delay-slot assignments mean
  the helper's source shape is not a plain void function; one attempt (score
  240, 856 B — CW folded my helper's read-back return away, merged my two
  inline copies' error blocks differently, and dropped several reloads of
  `field_1C` into `v1` reuse). Block placement of the vtable call and the
  B94/DAC/BCC s2-flag structure need CW's exact scheduler.
- Register plan to reproduce: s0=byte, s1=reader, s2=char/cursor(B80 loop),
  s3=cursor(main loop).
