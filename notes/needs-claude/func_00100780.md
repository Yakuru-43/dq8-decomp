# func_00100780 — boot wrapper, same tail-call wall as func_00100860

- Size 32 B (0x100780–0x1007A0), text_1004F4.s / text_100500.s,
  `nonmatching func_001007A0, 0x54` follows.
- factory-1 (Qwen) session 2026-10-21: ~7 attempts, not matched.

## What it is

```
addiu $sp, $sp, -0x10
sd    $ra, 0x0($sp)
jal   func_001007A0
nop
ld    $ra, 0x0($sp)
jr    $ra
addiu $sp, $sp, 0x10        <- in the jr delay slot
nop
```

Call-only wrapper around `func_001007A0()` (20 callers per `build/funcdb.tsv`,
e.g. `func_00102B90`). Passes no args, sets no return value. Byte-identical
shape to `func_00100860` (see its note: same wall, same boot TU).

## Attempts (all -O3)

- `void(void)` wrapper calling a `void(void)` / `s32(void)` extern → tail
  jump `j func_001007A0; nop` (8 B). Also with K&R `()` callee decl and K&R
  wrapper definition, with `s32` wrapper `return func_001007A0();`, and with
  an `s32` wrapper calling a `void` callee without a return.
- Struct-return wrapper (16 B struct forwarded) → tail jump as well.
- Empty `asm("");` after the call → still tail-jumped (asm folded away).

Per the func_00100860 note: `-O2` keeps the frame but schedules the epilogue
as `ld ra; addiu sp; jr ra; nop` (wrong order vs the original), and the only
permuter score-0 there needs `volatile` + `while (0)` (lint-refused).
