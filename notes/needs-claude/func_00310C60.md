## The blocker
The double guard `beqz $s0 / nop / beqz $v0 / nop` after the SINGLE
`jal func_0015F490`. CodeWarrior will not keep two tests on one value:
- two calls `handle = f(); handle2 = f();` → CW does not CSE external calls
  (two `jal`s emitted), score 31.
- duplicate `if (handle == 0) return;` twice → CW collapses to
  `beqz $s0` + inverted `bnez` + a duplicated 3-word epilogue.
- `ctx = handle;` alias local, check both → same collapse (score 29).
func_00310CF0 (next row, same split) has the identical shape with `beqz $s1`
(delay `daddu $s2,$v0`) `beqz $s2`, where both registers are used later —
so the family really carries two locals from one getter call. Suspect a type
or declaration difference (e.g. one local `u32`, the other a pointer type,
or one obtained via a macro/inline wrapper that CW does not number together).
