## What it does
Right-aligns a decimal number into a buffer. Calls `func_0022A880(value)`
for the digit count, pads with `func_00133CB8(out, &D_003C7798)` while
`i < count - digits`, then per digit extracts `value / 10^(digits-1)`
(`func_00210DD0(10, n)` = pow), indexes `D_003A53A0[]` (2-char digit
strings), and reduces `value %= pow10`. Terminates with `out[outPos] = 0`.
Two integer divisions by a runtime value — the original wraps each in
CodeWarrior's trap-checked form `bnez $divisor, ok; div; break 0,7; ok:`.

## Best C (in this note's bottom; also not committed)
The register-allocation part is SOLVED: locals must be declared/assigned in
order `outPos` (→ s3), `digits` (→ s2), `i` (→ s1), params `out`→s5,
`value`→s4, `count`→s0; `outPos = 0;` **before** `digits = func_0022A880(value);`
swapping from the intuitive order was required (see saved-registers idiom).
Guard `if (out == 0) return;` is the leading `beqz $s5, epilogue` with
`daddu $s0, $a2` in its delay slot.
