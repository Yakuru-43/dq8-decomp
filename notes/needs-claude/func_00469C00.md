## What it is
Bingo-board scorer, `void`-ish (returns `count` in v0, no callees, frame 0x70,
no ra save). A 25-entry u32 buffer at `sp+0` (100 B), zeroed by a byte loop
with a `beqz` on the pointer (top-guarded `do {} while`, counter `u32` 100
counting down — `bnez`, not `bgtz`). Grid: `Cell grid[25]` at `D_0047FE60`
(`.data`), 8-byte cells, flag at +4, row stride 40 = 5 cells. Then:
- loop 1 rows: all 5 flags of row i set → `count++`, `buf[i * 5 + j] = 1` (j inner).
- loop 2 columns: same with base `D + j * 8`, offsets +4, +0x2C, +0x54, +0x7C, +0xA4; store `buf[i * 5 + j]` (i inner).
- main diagonal: five **separate `.data` symbols** loaded `lui %hi`/`lw %lo($v1)`:
  D_0047FE64/FE94/FEC4/FEF4/FF24 (= grid +4, +0x34, +0x64, +0x94, +0xC4) → `buf[i * 6] = 1`.
- anti-diagonal: D_0047FE84/FEA4/FEC4/FEE4/FF04 (+0x24, +0x44, +0x64, +0x84, +0xA4) → `buf[i * 4 + 4] = 1`.
- `if (count != 0)` tail: 25-iteration loop, `i / 5` and `i % 5` via the
  divbyzerocheck idiom (guard once: `bnez $a3; div; break 0,7`, divisor `addiu $a3,$zero,5` hoisted
  out of the loop and *reused* as the stored 5; second plain `div`+`mfhi`).
  If cell flag set: `beql buf[i]` → `lw $v1,-0x5AA8($gp)` (D_003E17C8, a pointer
  global) in the delay slot AND a second `lw` on the fallthrough;
  `sb 6` via `b`'s delay slot when buf[i] != 0, `sb 5` on the beql target.
  Registers: counter $t0, q in $a1 (`(q*5)<<3` = row*40), `col<<3`, a0=6, a3=5.
