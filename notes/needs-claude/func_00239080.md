   bottom-tested `slti $v1,$a1,0x100; bnez` — the draft already reproduces this).
2. Outer loop `i` in `$s0` over `struct { s32 a; s32 b; } D_003A6770[]`:
   base `lui/addiu` re-materialized **inside** the loop into `$t0`, entry ptr
   `$a3 = $t0 + i*8`, `id = lw $a2,0($a3)`; `id == 0` returns.
3. Inner loop `j` in `$t1` from 0, tested `slt $v1,$t1,$s0; bnel` with
   `sll $a0,$t1,3` in the delay slot (precomputes next `(j*8)` into `$a0`);
   body reloads `entry->b` every pass (`lw $v1,4($a3)`), `addu $a0,$t0,$a0`,
   `lw $a1,4($a0)`, `beq $v1,$a1, <dup>`. Duplicate found →
   `jal DebugPrintf (=func_00145C00)` with `%lo(D_003C8720)` in the delay slot,
   then a spin `5x nop; b -6; nop` — **the plain C `while (1) { }` reproduced
   that spin byte-exactly at -O3**, no trick needed.
4. After the inner loop: reload `lw $v1,4($a3)`; `bltz $v1,<range>`;
   `slti $at,$v1,0x100; beqz $at,<range>`; else `sw $a2,0($v1')` into
   `D_004162F0[b]` (base re-materialized `lui/addiu` at +0x9C). Out-of-range →
   `jal DebugPrintf(D_003C8750)` then `b` back to the loop increment
   (`b <top>; addiu $s0,$s0,1`).
