the thread, delete the sema, free every entry's handle and reset the pool.

## Structure of the asm

1. Guard `IdValid(pool->thread) == 0 -> return`, then `if (0 <= pool->thread)`
   (slt+bnez, constant-on-left) around the join loop + `TerminateThread` +
   `DeleteThread`; else-path jumps straight to the cleanup at 0x309F20.
2. Join loop (0x309E2C..0x309F10): top loads `entries`, three checks
   (`entries == 0`, `IdValid(thread) == 0`, `sema < 0`) whose FALSE edges all
   jump to **shared stubs** (EF8/F00/F08, each `daddu $v0,$zero,$zero; b EB0`)
   that materialise the test value 0 and join a single `beqz $v0, F10` exit
   (break). The counting loop over entries is **rotated: bottom test**
   (`i = 0; b EA0; body; EA0: slt $v0,$a2,$a0; bnez -> body`), where
   `active += (u8)(inUse != 0 ? 1 : (state == 1))` (sltu/beqz/lh/xori/sltiu/andi 0xFF).
   Fall-through (0 < active, `slt $v0,$zero,$a3`): reload thread/sema checks
   (`continue`-style back edges to E2C), then `PollSema`, `bgez -> continue`,
   `SignalSema(sema)` back edge to E30 with `lw $a1,0($s1)` in its delay slot.
3. Cleanup: `thread = -1`; `if (0 <= sema) DeleteSema(sema)` (beqz to an
   out-of-line block at FD4); `sema = -1` (delay slot of the back edge); loop
   `i < pool->count` freeing handles (`inUse != 0` -> `handle != 0` ->
   `func_00159810(func_0015F450(), handle + 8, ident)`) then resetting
   inUse/handle/state/logId(-1) per entry; final block zeroes entries/count/
   allocator, `sb -1` at 0x10, sema=-1, thread=-1 (delay slot).
