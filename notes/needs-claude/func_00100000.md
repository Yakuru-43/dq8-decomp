# func_00100000 (SLES_539.74, 0x00100000, 8 bytes) — factory-1

Entry padding in front of the handwritten `_start` (`asm/SLES_539.74/
text_100000.s` lines 12–15): two `nop`s, no `jr $ra` — control falls through
into `_start` at 0x100008 (`nonmatching _start, 0x210`). Not a real function.

## Attempts

1. Empty C `void func_00100000(void) { }` → `jr $ra; nop`:
   `DIFF at +0x0: mine 03E00008 orig 00000000`. No legal C can fall through
   the end of a function, so this can never match.
2. Handwritten `asm void func_00100000(void) { nop \n nop }` (the autodecomp
   `kind == "asm"` shape) → **MATCH** (8 bytes, 3.0.1b151-050317 -O3). But
   `src/*/asmfunc/` is git-ignored, gate-refused and excluded from progress
   (CLAUDE.md, `tools/readme_progress.py`), and autodecomp only generates such
   files for VU0 code (`tools/autodecomp.py`, `VU0` regex) — so committing is
   not an option either.
