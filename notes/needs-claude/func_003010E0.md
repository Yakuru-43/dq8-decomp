## What it does (semantics fully settled)

1. `p = *(void **)(arg0 + 0x10); kind = ((u8 *)p)[1];`
2. `tab = (Tab *)D_003E10E4;` `base = (u8 *)tab->base + kind * 2;` — the
   pointer field is at `tab + 0x10` (`lw $v0, 0x10($a0)`), the index scaled
   by 2 (`sll $v1, $v1, 1`).
3. `count = *(u8 *)(base + 0x30); total = *(u8 *)(base + 0x31);`
4. clamp: original is `bgtz $s1, +2` with `addiu $s1, $zero, 1` inline,
   i.e. `if (count <= 0) count = 1;` where CW keeps the store inline after
   an inverted `bgtz` (`count`/`s1` loaded via `lbu`, so `<= 0` is the
   `func_003010A0` idiom — unsigned value, signed test, not folded).
5. `if (total < count) total = count;` — `slt $at,$s0,$s1` + `beqz` +
   `daddu` (matched exactly).
6. `r = func_00132D38();` — called with no argument setup; its `$v0` is
   used directly as the `div` dividend. Probably a random/timer getter.
7. `return r % (total - count + 1) + count;` — the original wraps the
   `%` in CodeWarrior's trap-based divide guard: `bnez $v1, .L00301144;
   div $zero, $v0, $v1; break 0, 7`, then `mfhi $v0; addu $v0, $v0, $s1`.

Saved regs: `s0 = total`, `s1 = count` (achieved by declaring `count`
**before** `total` — allocation is reverse of declaration order here),
frame 0x30, `ra` at 0x20.

## Opus attempt 2026-10-24

The divide guard is solved: it is CodeWarrior's `divbyzerocheck` option, given
per file as `// flags: -flag divbyzerocheck` (same as `#pragma divbyzerocheck on`,
which the lint refuses). With it the guard, the clamp (`count < 1` gives the
inline `bgtz`) and the s0/s1 allocation all match; 7 words still differ:

- `+0x10..+0x24`: the original loads `p` into `$v0`, `kind` into `$v1`, the table
  into `$a0`, and adds `idx + base` (`addu $v0, $v1, $v0`); mine hoists the gp
  load first and adds `base + idx`.
- `+0x70`: original `addu $v0, $v0, $s1` (mod + count), mine `addu $v0, $s1, $v0`.

`count + r % n`, `kind * 2 + base`, u8/u16/s16/u32 locals, a `Range { u8 min, max; }`
struct, a static inline lookup, C++, `-O4`, `-opt nopeephole` / `noschedule`:
none moves either diff. Both commutative pairs come out swapped, so look for a
shape where the other operand is evaluated first (an inline helper returning
`rand() % n`, or the index coming from a call/inline accessor on `arg0`).
