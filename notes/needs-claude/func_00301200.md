# func_00301200 — needs-claude

- asm: `asm/SLES_539.74/game_301200.s`, size 0x50 (76 + pad nop), queue row 30.
- What it seems to do: read byte 1 of the struct at `*(arg0 + 0x10)` as a
  modulo divisor, clamp it to at least 1, call `func_00132D38()` (the game
  `rand()`), return `rand() % divisor + 1`.

## The blocker

CodeWarrior **elides the div-by-zero guard** (`bnez $s0, L; div; break 0, 7`)
in every C shape I tried, but the original keeps it. My best C compiles to
19 instructions, the original has 21 (bnez+break) and orders `addiu $v0, 1`
after the callee-saved reloads:

```
orig:                                  mine:
bgtz  $s0, +8                          bgtz  $s0, +8        (matched)
nop                                    nop                  (matched)
addiu $s0, $zero, 1                    addiu $s0, $zero, 1  (matched)
jal   func_00132D38                    jal   func_00132D38  (matched)
nop                                    nop                  (matched)
bnez  $s0, +8            <-- missing   div   $zero, $v0, $s0
div   $zero, $v0, $s0                  mfhi  $v0
break 0, 7             <-- missing     addiu $v0, $v0, 1    <-- early
mfhi  $v0                              ld    $ra, 0x10($sp)
ld    $ra, 0x10($sp)                   lq    $s0, 0x0($sp)
lq    $s0, 0x0($sp)                    jr    $ra
addiu $v0, $v0, 1                      addiu $sp, $sp, 0x20
jr / addiu $sp                          (same)
```

Prologue/epilogue (`addiu -0x20`, `sd $ra,0x10`, `sq $s0`, `ld`, `lq`) all
match. `if (divisor < 1)` gives the exact `bgtz/nop/addiu` clamp;
`<= 0` gives `blezl` with the `addiu` in the delay slot (wrong).

## Best C (68 bytes vs 76, diff at +0x28)

    s32 divisor;

        divisor = 1;

## What I tried (all elide the guard)

1. `if (divisor <= 0) divisor = 1;` → `blezl`+delay-slot `addiu`, no guard.
2. `if (divisor < 1) divisor = 1;` → correct `bgtz` clamp, guard still gone.
3. Separate `rem` local — identical output.
4. Test on one local (`count > 0`), assign another (`divisor`): `blezl`,
   guard gone.
5. Ternary `divisor = divisor < 1 ? 1 : divisor;` — identical to (2).

## Notes for the fix

must hinge on something I can't see from C alone: maybe CW only proves
nonzeroness when the clamp is SSA-merged one way vs another, or the original
