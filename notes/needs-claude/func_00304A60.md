## What I tried (9 attempts)
- `u32` value: cap compiles to 32-bit `sltu` + `lui 0x8000` — never the
  64-bit `slt`. Also `(s32)value < 0` then `value >= 0x80000000LL` lets CW
  **fold the whole cap** (range [0,0x7FFFFFFF] <= cap): 84 B, gone.
- `s32` value: same `sltu` problem, plus CW reuses `$a0` for the value.
- `s64` value + `(u32)(… + delta)`: keeps everything (folding does not fire
  on the s64 `value < 0` — `bltz` survives), cap is signed `slt`. Casts
  `(s32)value` in the negative test add a `dsll32/dsra32` copy — must stay
  plain `value < 0`.
- `>= 0x80000000ULL` gives `sltu`, not `slt`. Plain `0x80000000` or the
  left-hand `limit` local both give `slt` but the 2-word constant shortcut.
- Struct member access (`arg0->unk4150`) was required for `lw/sw 0x4150($a0)`
  offset addressing; with `(char *)obj + 0x4150` casts CW CSEs the address
  into `$a1` (`addiu`) and reuses `$a0`. Style precedent:
  `src/SLES_539.74/func_00304C00.c` (same pattern, float version, matched).
