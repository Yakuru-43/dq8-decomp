# func_00257200 (SLES_539.74, 48 B incl. padding, asm range 0x257200-0x257230)

## What it does
Leaf comparator over two structs with an `s32` field at offset 4
(`lw $v1,4($a1)`, `lw $v0,4($a0)`). The delay-slot `addiu $v0,$zero,1`
executes on **both** paths, so:

```c
if (b1 < a1) { return 1; }        // taken: v0=1 from the delay slot -> jr
return -(1 < b1);                  // fall-through: slt v0,v0,v1 ; negu
```

## Original asm
```
lw   $v1, 0x4($a1)
lw   $v0, 0x4($a0)
slt  $at, $v1, $v0
bnel $at, $zero, .L
 addiu $v0, $zero, 0x1
slt  $v0, $v0, $v1        # 1 < b1, constant 1 shared with the return
negu $v0, $v0
.L: jr $ra / nop          (+ 3 padding nops to 0x257230)
```

## Diff (mine vs orig)
Mine (44 B): identical lw/lw/slt, then
`beql $at` + `slti $v0,$v1,0x2` delay slot + `b` + `nop` +
`addiu $v0,zero,1` + `xori $v0,1` + `negu` + `jr` + nop.
Two CW choices to flip:
1. **branch polarity** — CW inverts to `beql` and puts the 3-instruction
   block at the branch target (extra `b`+`nop`); original keeps the block
   in the fall-through and takes `bnel` to `jr`.
2. **constant folding** — CW folds `1 < b1` to `slti 2; xori 1`; the
   original uses a register-materialized `li 1` shared with the `return 1`
   (`slt $v0,$v0,$v1`). The `s32 one = 1;` local does not stop the fold.
