## What it does

`func_00102840(struct Block *obj, struct Src *src) -> u32`. Reads a byte via a
pointer at src+4 (`lw v0,4(a1); lb v0,0(v0)`, so the byte is an `s8`), masks
`& 0x40` and keeps the result in `$v1` for two later `beqz`s. Loads fields:
0x228 count (s32, `lw`), 0x220 f220 (`lwu`), 0x224 (`lwu`, in the flag40
branch's delay slot — live on both paths), 0x234 n234 (`lwu`, flag40 path
only), 0x230 f230 (`lw`, once, tested twice), 0x18 base (`lw`).

- flag40 path: `end = base + f224 + ((n234*4+15) & ~15)` (the round-up uses
  `pcpyld $a2,$zero,-0x10` + `and` = u32 `& ~15`), then
  `ptr = (char *)((u32)end + count*16)`; else `ptr = base + f224 + count*16`.
- `if (f230) ptr += 16;` (beqz + nop + addiu); then `ret = *(u32 *)ptr;` sits
  in the delay slot of the **second** `bnez $t1` — so it reads ptr *after* the
  +16, on both paths, and is the return value (single `jr $ra`, `$v0` never
  touched again).
- f230 != 0: `ptr -= 16; *(u128 *)(obj+0x200) = *(u128 *)ptr;` (block at
  0x294C); else `if (count == 9) { ptr -= 16; count -= 1; same copy; }`.
- `subu $t5,$t5,count*16` is in the delay slot of the loop guard `beqz $at` —
  it runs **unconditionally**, so write `psrc = ptr - count * 16;` *outside*
  the `if (0 < count)`. The guard itself is `sltu $at,$zero,$t0` + `beqz`,
  `daddu $t4,$zero,$zero` (i=0) hoisted before it, `daddu $t3,$a0,$zero`
  (dst=obj) inside.
- q120 loop (0x2920): `lq 0(t5) / sq 0x120(t3)`, both bases increment, back
  edge `bnez` on `sltu $t1,(s32)i,(u64)count` — my s32 `i < count` gave `slt`.
- **Both** exits of the guard load `dsll32 $t0,$a1,0` (a1 = f220 from entry):
  `count = (s32)obj->f220;` after the if, then
  `obj->f14 = obj->f18 + (s32)f220;` whose `sw` is in the delay slot of the
  second `beqz $v1` (runs even on the flag40==0 return).
- flag40 tail: `pw = (u32 *)(end - n234*4)` in the delay slot of
  `beqz $at, <return>` (unconditional), guard `sltu $at,$zero,$a3; beqz $at`
  — `0 < n234` on u32 **materializes into $at**, mine folded to `beqz $a2`.
  Copy loop: `lw 0($a2) / sw 0x288($a0)` with **$a0** (obj!) incremented by 4
  in the back-edge delay slot; the j register only feeds the `sltu`.
