# needs-claude: func_00210EC0

CLASS structural score=46 (45 words differ, 188 vs 192 bytes) — best attempt, `-- -O3`

**Size:** 192 bytes (0x210EC0 – 0x210F80), binary SLES_539.74.

**What it does:** reads the tick counter `D_003E0964` (gp-relative), computes
`cur = tick / 300`, `prev = cur - 1` clamped to 7 when negative, the fraction
`frac = (f32)(tick % 300) / 300.0f`, then writes to `a0`:

- `+0x0`: `(D_003A5910[cur*2] - D_003A5910[prev*2]) * (1 + frac)` (via `madd.s`)
- `+0x4`: `4400.0f` (from `(f32)4400`, i.e. `cvt.s.w` of an integer constant)
- `+0x8`: `(D_003A5914[cur*2] - D_003A5914[prev*2]) * (1 + frac)`
- `+0xC`: `1.0f` stored as an **integer** (`lui 0x3F80` + `sw`, not `swc1`)

Also has a dead `mtc1 $zero,$f3` + `adda.s $f3,f5` / `adda.s $f3,f1` pair.

## Why it cannot match with this compiler

The original's **first** `div` (the `/ 300` for `cur`) is wrapped in a
divide-by-zero trap guard:

```
addiu  $v0, $zero, 0x12C
bnez   $v0, .L00210ED4
div    $zero, $a1, $v0
break  0, 7
.L00210ED4:
mflo   $v0
```

The **second** `div` (the `% 300`, same constant divisor) has no guard.
mwccps2 3.0.1b151 never emits this guard: scratch compile of `a / b` with
variable divisor at -O3 shows plain `div`/`mflo`/`mfhi`, no `bnez`/`break`;
`-help search=div|trap|zero` lists no matching option; `-f div_zero_to_trap`
is "Unknown option 'f'". This is the same wall as func_00210C90
(`notes/needs-claude/`, itoa) — no matched precedent repo-wide; suspect the
original was built with an mwccps2 build/flag that traps division by zero.
The 2026-10-22 compiler sweep (8 builds x flags, see notes/weekly) flipped
nothing, so this needs a compiler-side answer, not a C trick.

Even with the guard, scheduling is off: mine interleaves the two `sll ...,3`
index scales and the second `lui`/`addiu 0x3A5914` pair differently, and
assigns tick/prev to different regs ($a1/$a2 vs orig $a1/$a2/$t0/$t1).

```c
extern s32 D_003E0964;
extern f32 D_003A5910[];

struct TimedPos {
    /* 0x00 */ f32 unk0;
    /* 0x04 */ f32 unk4;
    /* 0x08 */ f32 unk8;
    /* 0x0C */ s32 unkC;
};

void func_00210EC0(struct TimedPos *out) {
    s32 tick = D_003E0964;
    s32 cur = tick / 300;
    s32 prev = cur - 1;
    f32 frac;
    f32 d0;
    f32 d1;

    if (prev < 0) {
        prev = 7;
    }
    frac = (f32)(tick % 300) / 300.0f;
    d0 = D_003A5910[cur * 2] - D_003A5910[prev * 2];
    d1 = D_003A5914[cur * 2] - D_003A5914[prev * 2];
    out->unk0 = d0 + frac * d0;
    out->unk4 = (f32)4400;
    out->unk8 = d1 + frac * d1;
    out->unkC = 0x3F800000;
}
```

## What was tried
