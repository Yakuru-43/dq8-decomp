What it does: splits a path string (arg2) at '/' '.' '\0' '_' '-' (a special
char that is the last char is kept in the component); each component is
looked up in a string pool: `pool = (char*)arg1 + arg1->off4`, entries are
NUL-terminated, count = `arg1->0xC` (u32), walked with `pool += strlen+1`
(func_001341D8 = strlen, func_00133BE0 = strcmp). On miss returns 0 after
writing one 0 byte; on hit writes the index as a 1- or 2-byte varint
(`idx < 0x80`: one byte; else `(idx&0x7F)|0x80`, then `idx>>7`) to arg0 and
continues with the next component (the separator char starts the next
component, buf[0]=sep, untested store of the char after it); on end of
string writes a final 0 byte and returns 1. Prologue zeroes a 64-byte stack
buffer at sp+0x70 via an `if (p != 0)`-guarded do--while(--n).
