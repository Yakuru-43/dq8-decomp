## What it is
Twin of func_00103AB0 (needs-claude, same dir) on the **put** side of the same
MSL-style streambuf: `Writer` with vptr at 0x00, `Elem *pptr` at 0x14, `Elem
*epptr` at 0x18 (Elem = 4-byte `{u16 value; u16;}`), 12th virtual (0x34) =
overflow returning s32. Shape:
`s64 avail = epptr - pptr` (CW emits `subu; bgez→sra 2; addiu 3; sra 2` for the
signed /4), `s64 total = min_s64(avail, n)` (same address-select pattern —
see AB0's note, it reproduces byte-exact), `if (total > 0) {8-at-a-time copy
loop + 1-at-a-time tail; src += (s32)total; pptr += (s32)total; n -= total;}`
then `if (n > 0) { do { ch = src->value; src++; if (pptr < epptr)
{store+read-back} else { ch = overflow(); } if (ch == -1) break; total++;
} while (--n > 0); } return total;`.

Two proven-local details:
- the byte loop stores `p->value = (u16)ch;` then **reloads** `ch = p->value;`
  through the same register the `sh` used (`lhu $v0,0x0($v1)` right after
  `sh $a1,0x0($v1)`) — CW does not store-forward here; `(w->pptr - 1)->value`
  after the bump gives the wrong `lhu -0x4($v0)`;
- `if (0 < (s32)total)` (constant left) gives `sltu $at,$zero,$v0` and
  `9 <= (s32)total` gives `sltiu+bnez`, both correct.

## Remaining diff (bulk block only, everything else aligned)
The 8-at-a-time loop: orig computes the two +0x1C addresses up front
(`addiu $v1,$t0,0x1C; addiu $a0,$t1,0x1C`), loads elements 0..6 inline and the
**8th** last via those temp regs (`lhu $v1,0x0($v1)` at +0x3CF0) with its store
in the back-edge delay slot (`sh $v1,0x0($a0)`), i.e. 21 words per iteration.
Mine loads `lhu $v1,0x1C($a2)` eagerly and stores it immediately, keeping the
delay slot of `bnez` empty — 18 words, score 94. Statement text is
`out[k].value = cur[k].value` ×8 then `out += 8; cur += 8; i += 8;`
`while (i < lim)` — CW scheduled all 8 load/store pairs adjacently. Ideas:
interleave (store k, load k+1); write the last pair after a `;` split; make the
loop counter signed; declare `lim` as `s32`.

Also register naming: orig keeps the loop index in `$a3` (mine `$a1`), the src
cursor in `$t0` and out in `$t1` (mine `$a2`/`$a3`) — declaration order of
`out`/`cur`/`i` per the saved-registers idiom.

Note the cold-block trap from AB0 **does not** appear here: CW already places
the overflow virtual block at the tail with `b →` the shared `-1` test, so the
AB0 blocker is about that file's load-arm falling into the test.
