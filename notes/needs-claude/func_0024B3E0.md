## What it does

Search over an array of 40-byte entries at `a0+0x24` (`a3 = lw 0x20(a0)` = count):

- skip entry if halfwords at +0x2 or +0x4 are 0;
- if `mode == 3` skip if halfword at +0x6 is 0; if `mode == 2` skip if it is non-0;
- for `j` in `0..mode`: `v = half at entry+2+j*2`; if `v == 0` break; find the first
  `k` in `0..2` with `used[k] == 0 && keys[k] == v` (`a1` = `s32 *keys`), mark it 1,
  break; if `k == 3` no slot matched → `ok = 0`, break the j loop;
- if `ok == 1` break the outer loop. After the loop (both via break and via
  exhaustion — the tail block `.L0024B4E8` is shared with the `i >= count` fallthrough):
  `if (entries[i].f0 == 0) ok = 0; return ok == 1 ? &entries[i] : 0;`.
- `ok` (t4) is never initialized in the prologue: with `count <= 0` the original reads a
  garbage t4 in the tail. Do not initialize it in C (an init store breaks the match);
  the same UB is fine.
