## What it does
`D_003E17B0` is a gp-relative pointer to an array of 64-byte slots (floats at +0x04, +0x10,
+0x34). For i in 0..4 and j = i+5: `slot.f34 += c1` (both slots), `slot.f04 -= slot[i].f34`
(j's f04 subtracts *i's* f34), `slot.f10 += c2`, then `slot.f10 = func_13BCA0(slot.f10)`
(the fptodp-proto callee `f32 func_13BCA0(f32)`; result stored, j's store sits in the
back-edge `bnez` delay slot). c1 = D_003DF764, c2 = D_003DF6D4 (gp-relative f32 globals,
loaded once per iteration at loop top, above the jals). Tail: `if (D[4].f04 < 0.0f &&
D[9].f04 < 0.0f) return 1; return 0;` (plain `bc1f`+`nop` chain to one v0=0 stub,
`b <epi>; addiu v0,1`). Prologue/frame/loop form all match byte-exact: `do {} while (i < 5)`,
i→$s3 declared first, j→$s2, shifts hoisted to $s1/$s0, table base reloaded before every
addressing (matches: stores kill the CSE).

## The residual diff (+0x28..+0xB0, 4 words + mirrors)
Original: `lwc1 $f2,-0x7B0C(gp); lwc1 $f1,-0x7B9C(gp)` at loop top — the f34-addend in $f2,
