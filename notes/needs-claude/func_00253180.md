## What it does
Pool search. `D_003E0C14` is a pointer to an array of 0xE0-byte records,
`D_003E0C18` a signed-byte count. If `arg0 > 0`: scan the records, return the
first whose `id` (0x5C) equals `arg0`, else 0. Else: return the first record
whose `state` (0x58) is negative, else 0. Null pool returns 0.
