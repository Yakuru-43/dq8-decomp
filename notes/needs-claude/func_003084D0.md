# func_003084D0 — needs Claude

- **Size:** 128 bytes (0x3084D0–0x308550), `asm/SLES_539.74/game_3084D0.s`
- **What it does:** bitmap bit-test. `a0` = struct pointer with a 64-word
  (`u32 words[0x40]`) bitmap at offset `0x50`; returns `(words[bit / 32] &
  (1 << (bit % 32))) != 0`, or 0 when `bit < 0 || bit >= 0x800`. The init
  function `func_003085F0` zeroes exactly those 0x40 words, so the struct
  guess is solid. Neighbour `func_00308550` (set/clear variant with `a2`
  selector) shares the identical prologue, so whatever solves this one
  probably unlocks it too.

## Best C (score=19, all 30 words same size, prologue + tail already exact)

```c
// range: 0x3084D0 0x308550
#include "common.h"

struct BitMap {
    char pad[0x50];
    u32 words[0x40];
};

s32 func_003084D0(struct BitMap *map, s32 bit) {
    s32 valid;
    s32 mask;

    if (bit >= 0 && bit < 0x800) {
        valid = 1;
    } else {
        valid = 0;
    }
    if (valid != 0) {
        mask = 1 << (bit % 32);
        valid = (map->words[bit / 32] & mask) != 0;
    }
    return valid;
}
```

The `if/else` materialising `valid` is what makes CodeWarrior emit the
prologue (`bltz a1, fail; slti $at; beqz $at, fail; li $v0,1`), the shared
fail block (`b test; daddu $v0,zero,zero`) and the tail
(`b L540; daddu $v0,zero,zero; jr $ra`) **byte-exact**.

```
      with the %32 fixup (andi/beqz/addiu-0x20/sllv $v1); the original
      runs the %32 block fully first (bgez/andi/beqz/addiu/sllv $v1),
      then the /32 block (bgez/sra/addiu/sra/sll/addu), lw, and, sltu.
```

Two problems, both in `if (valid) {...}`:
1. CodeWarrior emits `beqz` over an inline body; the original tests with
   `bnel $v0,$zero` forward-branching to a cold body, fall-through returning
   0, `li $v1,1` stolen into the delay slot.
2. Body scheduling: original keeps the `%` block and the `/` block
   contiguous and `%`-first; mine interleaves `/`-first. (Writing
   `(1 << (bit % 32)) & map->words[bit / 32]` did not fix the order — CodeWarrior
   hoists the load/address chain; a `mask` local as above keeps `%` first but
   the blocks still interleave.)
