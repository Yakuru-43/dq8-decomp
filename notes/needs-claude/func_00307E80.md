## What the original does that my C does not

1. **Materialized flag** (the known BB0 blocker). After the `work` guards:
   `addiu $v0,$zero,1` on the good path, and both guard-fail paths jump to a
   stub `b <test>; daddu $v0,$zero,$zero`; the test is `bnel $v0,$zero,<body>`
   with the work recompute in its delay slot. My `if/else flag = 1/0;
   if (flag != 0) {...} else {...}` gets fused: CW emits `beql $v0,$zero`
   with `daddu` in the delay slot and the else block laid out last (156 B).
2. **`idx` lives in `$a2`** across the whole function (the recomputes read
   `$a2`); CW gives my temporary `$v0` and frees `$a2`.
3. **`work` is recomputed twice** (`addiu $v1,$a2,0x64` in the `bnel` delay
   slot and again before the `/32` block) instead of CSE'd; my single `work`
   local is kept in `$v1`.
4. **Bit block before word block** (bit `% 32`, `sllv`, then `/32`), and
   `addiu $a1,$zero,1` for the shift materialized *before* the bit block;
   mine emitted word first and the `li` right before the `sllv`.

```c
s32 func_00307E80(void *arg0, s32 arg1) {
    s32 *bitmap;
    s32 idx;
    s32 work;
    s32 bit;
    s32 mask;
    s32 word;
    s32 flag;
    s32 result;

    idx = arg1 - 0x1F4;
    if (idx < 0 || idx >= 0x64) {
        return 0;
    }
    work = idx + 0x64;
    if (work >= 0 && work < 0x800) {
        flag = 1;
    } else {
        flag = 0;
    }
    if (flag != 0) {
        bit = work % 32;
        mask = 1 << bit;
        word = work / 32;
        bitmap = (s32 *)((char *)arg0 + 0x50);
        result = (bitmap[word] & mask) != 0;
    } else {
        result = 0;
    }
    return result;
}
```
