# func_003550B0

Size 144 (0x003550B0..0x00355140), SLES_539.74, asm/SLES_539.74/game_353E30.s.

What it does: guard `arg1 < 0` (bltz a1 right after prologue). Then a bottom-tested loop over 32 entries of a 48-byte-stride array (index*3<<4): `if (arg0[i].field_24 == arg1) break`. On hit: `arg0[i].field_00 = 3; arg0[i].field_24 = -1;`. On miss **or** arg1 < 0: `DebugPrintf(&D_003D38E0)` (one arg).

The tricky bits:
- **One register ($a2) is loop counter AND result.** Exhaustion edge is `addiu $a2,$zero,-1` with NO compare — then falls into the shared check `bltz $a2, printf`. The arg1<0 path is `b <check>; addiu $a2,$zero,-1` (assignment in the delay slot). So `i = -1` is materialized on exactly the two miss edges, none on the hit edge.
- Back edge is plain `slti $v1,$a2,0x20; bnez $v1,<body>; nop` — NOT `bnel`; CW with bnel fills the delay slot with the body's first `sll`, the original keeps `nop`.
- `sd $ra,0(sp)` sits INSIDE the arg1>=0 path (after bltz, before the b-to-test); the arg1<0 path reaches `jal DebugPrintf` without saving ra (original quirk — epilogue always `ld $ra,0(sp)`).
