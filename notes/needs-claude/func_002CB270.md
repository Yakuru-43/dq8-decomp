## The two walls

1. **Extra `lui $v0, 0x4100`.** The original materialises `0x41000000` once, in
   the first `beql`'s delay slot, and that one register feeds `lw v1,0x20($v0)`,
   `lw $a1,0x0($v0)` *and* the `mtc1` of the `8.0f` return at `.LD4`. My C makes
   CW emit a second `lui $v0,0x4100` for the loads (mine 164 B vs 160 B). Tried:
   raw `*(u32 *)0x41000020` / `*(u32 *)0x41000000`, and a named local
   `u32 *work = (u32 *)0x41000000` with `work[8]` / `work[0]` — CW
   rematerialises the constant either way.
2. **if/else block placement.** With `if (work[8] != 0) {scale = X;} else {if
   (f()==0) return 10.0f; scale = Y;}` CW lays the *else* arm out as
   fall-through and inverts the test to `bnel $v1,$zero,<far>`; the original
   falls through into the `func_002B0950` arm with `beql $v1,$zero,.LE0`.
   Flipping the source to `if (work[8] == 0) {Y path} else {X path}` made it
   worse (172 B, score=34); `else if` spelling instead of nested `if` gave the
   identical 164 B output.
