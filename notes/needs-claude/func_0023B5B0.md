**What it does.** Script-command handler (same family as the already-matched
func_0023B4E0 / func_0023E440, which I used for style and for the `struct Tagged`
layout). arg0 is seven 8-byte `{s32 type; union {s32 i; f32 f};}` records at
0x00, 0x08, 0x10, 0x18, 0x20, 0x28, 0x30. arg1 is a mode.
- record 0x00 → `i` (`type == 1 ? (s32)v.f : v.i`) — loop start;
- records 0x08..0x20 → four floats (`type == 0 ? (f32)v.i : v.f`) built with
  four `swc1` into a 16-byte stack local (frame is exactly `addiu sp,-0x10`),
  read back once with `lq $a0, 0($sp)` before the loop, stored every iteration
  with `sq $a0, 0xD0($v1)`;
- record 0x28 → one float kept in `$f1`, stored `swc1 $f1, 0xE0($v1)`;
- record 0x30 → `count`, **only read when `arg1 >= 7`** — when `arg1 < 7` the
  `slti $v1,$a1,7; bnez` skips the block and `count` (=$a3) is used uninitialized
  in `addu $a2,$v0,$a3` at the loop entry (so in C it must be an uninitialised
  local, not a default value);
- loop `for (i = start; i < start + count; i++)`: reloads `D_003E0B24` each
  iteration (`lw $a1,%gp_rel(D_003E0B24)($gp)` in the back-edge `bnel` delay
  slot), null test `beqz $a1,<FC>; nop`, range test `lw $v1,0x2C($a1); slt $at,$v0,$v1;
  beqz $at,<FC>`, entry = `0x28($a1) + i*0x110` (`sll 4; addu; sll 4`),
  `beql $v1,$zero,<ret>; daddu $v0,$zero,$zero`, `sq`, `addiu i,1`, `swc1`;
  exit `b <ret>; addiu $v0,$zero,1`.
- **FC** is a shared block at 0x23B6FC `b <beql>; daddu $v1,$zero,$zero` that
  both the null test and the range test branch to (it sets `entry = 0` and
  jumps back into the `beql $v1` null check).
