# func_00471540 (MENU, 208 bytes, 0x471540..0x471610)

`s32 kind; union { f32 value; s32 count; S_Node *next; } u;`). Each pair
`i`: if `kind == 1` the payload is `(s32)` of the float at `+4`, else the
raw int. First two payloads become `first`/`second` (locals in `$s0`/`$s2`,
node copy in `$s1`). Then:

- `first == 0` -> `jal func_3089E0(D_003E0CAC, second)` (plain-C `if`, both
  call tests are `beql` with `lw $a0,%gp_rel(D_003E0CAC)($gp)` in the slot);
- else-if fall-through `first == 1` -> `jal func_308870(D_003E0CAC, second)`;
- third pair (offset 0x10/0x14 from `$s1`): if `kind == 3`,
  `sw $v0, 0x4($v1)` — stores the *call result* at `next->u.count` (`$v1` =
  0x14($s1), loaded in the `beql` delay slot; `lw $a0,0x10($s1)` for the tag
  happens AFTER both calls, in the `.LA8` fall-through and the `.LD8` `b`
  delay slot). If neither call ran, `$v0` is whatever it was — so model as an
  `s32 ret` assigned in both arms and stored uninitialized in the third case.
- returns 1.
