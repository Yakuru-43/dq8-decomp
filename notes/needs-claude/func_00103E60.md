## What it does

`s64 f(Ring *o /*s2*/, Entry *dst /*s1*/, s64 count /*a2, spilled to 0x40(sp)*/)`
— drains up to `count` 4-byte entries (`{u16 v; u16 pad;}`, only the u16
copied, `sh` at offsets 0,4,...,0x1C, stride 0x20) out of a ring `o`
(`head` at +8, `tail` at +0xC, both u32, raw addresses) into `dst`:

1. `avail = (s32)(tail - head) / 4` (the bgez/sra + addiu 3/sra 2 pattern).
2. `total = min(avail, count)` — **but the asm does it with the stack-slot
   select idiom**: `slt at,v1,v0; beqz at,A; sd v1,0x48(sp); b B; addiu
   v0,sp,0x48; A: addiu v0,sp,0x40; B: ld s0,0(v0)`. A plain C ternary gives
   `movz` instead (that is one of the diffs).
3. `if (total > 0)`: bulk copy, `if (n >= 9)` (sltiu <9 / bnez into the tail
   loop, `addiu a2,v0,-8` in its delay slot) then an **8-way unrolled
   do-while**: test at the bottom (`sltu v0,a3,a2; bnez v0,back`), body
   starts `lhu a1,0(t0); addiu a3,a3,8; addiu v1,t0,0x1C; addiu a0,t1,0x1C;
   sltu...` and the 8th copy is deferred into the loop-back delay slot
   (`bnez; sh v1,0(a0)` with `lhu v1,0(v1)` one insn earlier); `t0/t1`
   (src/dst) step `addiu +0x20` mid-body, `i` (a3) is a byte-free element
   counter compared **unsigned** against `n-8` and `n`. Then a scalar
   `while (i < n)` copy loop (t0/t1 step +4, store from a saved `a1`), then
   `dst += n*4; o->head += n*4; count -= total;` — all inside the `> 0`
   guard (the `dsubu` is NOT reached from the `blez s0` skip).
4. `while (count > 0)` pop loop, count **in the stack slot**: entry `ld
   0x40(sp); blez → tail`; `if ((u32)head < tail)` (`lw/lw/sltu/beql`, the
   vptr `lw t9,0(s2)` preloaded in the beql delay slot) → `lhu` from the OLD
   head after `addiu +4; sw` already updated it; else virtual slot 0x28
   (`jalr t9; daddu a0,s2`). The two paths merge at one `addiu v1,-1; beq
   v0,v1 → .L4008`; then `sh v0,0(s1); daddiu s0+1; ld v0,0x40(sp); addiu
   s1+4; daddiu v0,-1; bgtz v0,back; sd v0,0x40(sp)` — **plain `bgtz`, not
   `bgtzl`**, with the `sd` in its delay slot.
5. single tail `.L4008: b .L4028; daddu v0,s0,zero` — both exits (`-1` and
   loop end) share it → one `return total;`.

## Register plan the original settles on

Only `s0..s2` saved (`sq s0,0; sq s1,0x10; sq s2,0x20; sd ra,0x30`),
`s2 = o, s1 = dst, s0 = total`; `count` lives **in `0x40(sp)`** the whole
time (spilled at entry `sd a2,0x40(sp)`, reloaded in the pop loop). My
build keeps count in `s1` and uses `s0..s3` with `ra` at `0x40(sp)` — that
single allocation shift is why everything after +0x04 miscompares.

## Best C (got 400/480 bytes, score 118, structural)

```cpp
// range: 0x103E60 0x104040
#include "common.h"
extern "C" {
struct Entry { u16 v; u16 pad; };
struct Ring {                     /* vptr +0, head +8, tail +0xC */
    virtual void v_0x08();
    virtual void v_0x0C();
    virtual void v_0x10();
    virtual void v_0x14();
    virtual void v_0x18();
    virtual void v_0x1C();
    virtual void v_0x20();
    virtual void v_0x24();
    virtual s32 refill();         /* slot 0x28 */
    s32 field_04;
    u32 head;
    u32 tail;
};
s64 func_00103E60(Ring *o, Entry *dst, s64 count) {
    s64 avail;
    s64 total;
    Entry *ps;
    Entry *pd;
    u32 i;
    s32 v;

    avail = (s32)(o->tail - o->head) / 4;
    total = avail < count ? avail : count;
    if (total > 0) {
        s32 n = (s32)total;
        ps = (Entry *)o->head;
        pd = dst;
        i = 0;
        if (n >= 9) {
            u32 limit = (u32)(n - 8);
            do {
                pd[0].v = ps[0].v;
                pd[1].v = ps[1].v;
                pd[2].v = ps[2].v;
                pd[3].v = ps[3].v;
                pd[4].v = ps[4].v;
                pd[5].v = ps[5].v;
                pd[6].v = ps[6].v;
                pd[7].v = ps[7].v;
                pd += 8;
                ps += 8;
                i += 8;
            } while (i < limit);
        }
        while (i < (u32)n) {
            pd->v = ps->v;
            pd++;
            ps++;
            i++;
        }
        dst += n;
        o->head += n * 4;
        count -= total;
    }
    while (count > 0) {
        if (o->head < o->tail) {
            v = *(u16 *)o->head;
            o->head += 4;
        } else {
            v = o->refill();
        }
        if (v == -1) {
            break;
        }
        dst->v = v;
        total++;
        dst++;
        count--;
    }
    return total;
}
}
```

## What was tried

1. Indexing `dst[i].v = src[i].v` in a plain for loop → no unroll at all
   (296 bytes). The original is a hand-unrolled copy; auto-unroll does not
   fire for this loop.
2. `if (count < total) total = count;` → branch form but `daddu s0,s1,zero`
   in the taken path; ternary → `movz`. Neither gives the stack-slot select
   (`sd v1,0x48(sp)` + `addiu v0,sp,0x48/0x40` + `ld s0,0(v0)`); that shape
   likely needs `count` already spilled (pressure) — see register plan above.
3. while-rotated unrolled loop → top test, wrong rotation. do-while brought
   the bottom test but the body interleaving (`addiu v1,t0,0x1C` pair +
   deferred 8th copy in the loop-back delay slot) did not reproduce.
4. `break` vs. merged `-1` test: original merges the pop and vcall paths at
   one `addiu v1,-1; beq v0,v1`; mine duplicated the `-1` constant.

Remaining diff is schedule + allocation, not logic: byte size 400 vs 480,
first real diff at +0x4 (`sd ra,0x40(sp)` vs `0x30(sp)`) — everything
downstream is shifted by the extra saved register.
