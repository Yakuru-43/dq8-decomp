## What it does

Scans a parallel-table lookup until a negative `s8` terminator. `D_003D5120` is a
`s8` array at stride 10; `D_003D5122/5124/5126/5128` are `s16` arrays indexed
`i * 5` (same stride 10 — four separate base pointers with their own
`lui/addiu %hi/%lo`, so *not* struct member accesses off one base).
If `D_003D5120[i*10] == arg0` (found index `i`): the four shorts, sign-extended,
are stored as words through `out0..out3` and the function returns 1; a negative
byte at any point returns 0.

## Loop: byte-exact in the best attempt

Entry `lui v1,%hi(D_003D5120)`, `daddu t1,zero,zero` (i=0), `b` to the condition
block; condition block computes `((i<<2)+i)<<1 + v1`, `lb`, `bgez` back to the
body block (which holds the `beql a0,v0 → found` and the `i++`). This all matched
with the C above (single `lb` shared between condition and body).

## Remaining diff: the found block only

The four stores with `lh`-sign-extension schedule differently. Original
interleaves: computes all four addresses first (`t1`,`a0`,`v1`,`v0` =
`base_k + t3`, `t3 = ((i<<2)+i)<<1`), then a load/store pipeline where each
`sw` trails its `lh` by ~2 slots, and `addiu v0,zero,1` lands late (at +0x94,
between the last `lh` and the last `sw`). Mine (`*out0 = D_003D5122[i*5];` …)
puts the `addiu 1` at +0x84 and pairs address→`lh`→`sw` linearly; the register
allocator also puts address #1 in `$a0` where the original reuses `$t1` (i's
dead reg), cascading a swap through address #2.
