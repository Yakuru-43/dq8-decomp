## What it does

Fills two 64-byte name buffers on the stack (`func_003501B0` x2, then
`func_00350560(obj->4, obj->0x18, bufs)`), then for each of two 0xA4-stride
slots `slot = (s32)arg0 + i*0xA4`: if `func_00350330((s32 *)(slot + 0x19A4))`
(the `>= 0` getter), strcmp each buffer against the name at `slot + 0x19B0`
via `func_00133F78`; if **neither** buffer matches, return `slot + 0x19A4`,
else 0 after both slots.
