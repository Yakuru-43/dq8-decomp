## Blocker: the `slti 1, 5` arm and its dead block

After `beql (c<6) → epi (delay addiu v0,1)` the next instructions are
`slti $at, $v0, 5` with `$v0` still the `1` from the delay slot — always
true, so `beql → L00106C74` (the `jal func_00107730` block) is unconditional
and **0x6C68..0x6C70 (`addiu $a2,$a1,1; b epi; addiu v0,-1`) is unreachable**.
The reachable code is exactly the skeleton above; the dead pair smells like
a folded `switch (c)` case (range-test `c < 6`, then a case test against a
register CW pinned to 1) — plain C produces neither the `slti 1,5` nor the
dead `-1` arm (my draft folded it away: 120 vs 144 B).
