# needs-claude: func_0020E330

- **Size:** 0xC4 bytes (range 0x20E330 0x20E400), SLES_539.74, blocker `none`.
- **What it does:** per-slot record state machine on `obj->0xC`:
  - state 1: `func_0012C6C0(1, &type, &index)` (pointer result — `beqz`+nop);
    `type == 0x11` and `index >= 0` → clear the 28-byte slot at
    `obj + 0x6BC0 + (obj->0x9C0 * 0x1C)` and return 1, else fall to return 0
  - state 0: `func_0012C6C0(1, 0, 0)`; `func_0012D2C8(obj->0x9C0, 1)`
    (pointer result — `bnez`+nop) must be NULL, then `obj->0xC += 1`; return 0
  - other states: return 0
- **Status: 196/208 bytes, one instruction away.** The whole function is
  byte-exact except the addend order of one `addu` in the case-1 store address:

```
mine   addu $v1, $s0, $v1      /* v1 = obj + slot*28 */
orig   addu $v1, $v1, $s0      /* same result, other operand order */
```

  The `* 0x1C` lowering (`sll 3` / `subu` / `sll 2`) into `$v1` is identical;
  only the addend placement differs. Syntax order does not control it:
  `obj + slot * 0x1C` and `slot * 0x1C + obj` (and `*(s32 *)(slot*0x1C + obj +
  0x6BC0)`) all emit `addu $v1, $s0, $v1`. Same family as the mwcc arg-copy
  scheduling wall in `notes/needs-claude/func_0034E590.md`. The store uses
  `sw $zero, 0x6BC0($v1)`, so a form that folds a `+ 0x6BC0` into an `addiu`
  (e.g. an `int array[...]` index) is wrong; `slot*7` element forms pull an
  extra `addiu` too.

## Shape that got everything else (do not lose these)

- `switch` over `M2C_FIELD(obj, s32 *, 0xC)`, `case 0:` written first, then
  `case 1:`: reproduces the CW dispatch exactly (`beql ==1` with `addiu $a1,$sp,0x2C`
  in the delay, `beql ==0` with `daddu $a1,$zero,$zero`, default `b` to the
  epilogue with `daddu $v0,$zero,$zero` in its delay). Reversed source order
  swaps the bodies and turns the first compare into a plain `beq`.
- All zero-exits are `break` (→ shared `daddu $v0,$zero,$zero` stub + nop-delay
  branches); the single `return 1` stays inline (`addiu $v0,zero,1` early, `b`
  to the epilogue with the `sw` in its delay). Using `return 0` everywhere
  instead of `break` flips the guards to `beql`/`bnel` — wrong.
- `func_0012C6C0` / `func_0012D2C8` declared returning `void *` gives the
  `beqz`/`bnez` + nop (pointer test); an integer return gives branch-likely.
- Increment: `state = M2C_FIELD(obj, s32 *, 0xC); M2C_FIELD(obj, s32 *, 0xC) =
  state + 1;` — `+= 1` makes CW materialise `addiu $s1,$s0,0xC` and save `$s1`.
