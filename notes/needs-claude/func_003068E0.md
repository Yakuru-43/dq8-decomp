## What it seems to do
Record splitter over a text buffer. Walks `cur` (arg1) toward `end` (arg2);
each record must start with the 4-byte separator pattern
`sep[0] sep[1] sep[0] sep[1]`, where `sep[0]`/`sep[1]` are copies (taken at
function entry) of the two gp-relative bytes `D_003DFF90`/`D_003DFF91`
(`.data` at 0x3DFF90/1, gp_rel −0x72E0/−0x72DF).

- Header: three `func_00130F38` (SIMD memcmp, returns 0 on equal — see
  `asm/SLES_539.74/sdk_128868.s:9992`) checks:
  `cmp(cur, sep, 2)`, `cmp(cur, sep, 1)`, `cmp(cur, sep + 1, 1)`; each
  failure returns the (already advanced) cursor: cur+2 / cur+3 / cur+4.
  In the asm the advance is eager: `beql $v0,$zero,RET` with
  `addiu $s2,$s2,N` in the delay slot (falls through with s2 updated).
- Body: while `cur < end` (unsigned, `sltu`) and all three memcmp are != 0:
  tab (9) → advance, `*slot[1] = 0` if `slot[1] != 0`, end record;
  space (0x20) → skip; else if `slot[0] != 0`, append the byte and bump
  the write index. `slot = lines + count` — `count << 2` scaling, so
  `lines` is a pointer array and record n uses slots n and n+1.
- Record end: if `slot[0] != 0`, NUL-terminate `slot[0][written]`, `count++`
  (the `addiu $s0,$s0,1` sits between the `addu` and the `sb`).
- Falls out to `return cur` when `cur >= end`.

Registers: s3=lines, s2=cur, s1=end, s0=count, s4=slot, s5=written,
s6=`sp+0x8D` (= `sep + 1`, hoisted at +0x74 in the header and reused by the
inner loop); sep bytes live at 0x8C/0x8D(sp); frame 0x90, ra at 0x70.

## Diff vs original (score 58, structural)
Loops, the memcmp call sequence and the record tail now line up; the whole
prologue is off-by-scheduling and the header has the wrong branch shape:

1. **Prologue**: mine computes `addiu $s6,$sp,0x8D` at +0x10 and stores
   `sep[1]` through it (`sb $v0,0($s6)`); the original stores `sb $v0,0x8D($sp)`
   directly and only materialises s6 at +0x74 (start of the third check,
   recomputed each outer iteration).
2. **Header checks**: original per check
   `jal; beql $v0,$zero,RET; addiu $s2,$s2,N` — eager cursor bump in the
   delay slot, then `daddu $a0,$s2,$zero` for the next call. Mine (after
   `r = f(); cur += N; if (r != 0) return cur;`) emits `bnel` to the return
   and folds the bump into `addiu $a0,$s2,N` at the use sites; the third
   check ends `bnez $v0` + `addiu $s2,$s2,4` instead of `beql` + `addiu ...1`.
3. **slot/written registers swapped**: mine gets written=$s4, slot=$s5;
   original slot=$s4 (`addu $s4,$s3,$v0`), written=$s5 (`daddu $s5,$zero,$zero`
   — and note the original initialises written=0 *before* computing slot:
   `daddu $s5,zero` precedes `addu $s4,$s3,$v0` past the `b`).
4. `lbu $v1,0($gp)` in mine is a try_match link artifact (`.sdata` + gp_rel
   resolves 0 in the standalone link); real link gives `−0x72E0($gp)`.
