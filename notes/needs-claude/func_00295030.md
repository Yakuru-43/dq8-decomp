   constant store on every path: all three paths to the epilogue assign `$v0`

   makes CW emit it; CW's DCE removes it. The original single-TU build kept it.

   daddu  $s1, $a0, $zero     ; arg0 -> s1
   lw     $v1, 0x58C($a0)     ; base  -> v1 (unsaved temp!)

   jal    func_00296280
   sw     $v0, 0xE8($v1)      ; base->unkE8 = ret, using the pre-call v1

   sat in `$v1` across the call. That requires CW's intra-TU clobber/escape
   analysis (`func_00296280` is defined in the same TU and doesn't touch `$v1`).
   In a per-function TU CW conservatively spills `base` to a third saved reg
   (`s2` for arg0, `s1` for base, stack `0x40`) — see diff.
