## What it does

results are stored in a stack array `vals[2]` at `sp+0x48` (first result spilled
before the second call; second stored via `addiu $s0,$sp,0x4C` in the second
`jal`'s delay slot, in the first test's delay slot). Null tests: `vals[0]` is
**reloaded** `lw $a0,0x48($sp)` + `beqz $a0`; `vals[1]` is tested raw in `$v0`.
Then `arg0->field_68` loads into `$a0` in the first test's delay slot and is
used **both** as a pointer base (`[f68 + 0x1C8] |= 1` when `arg1 == 0`) and as a
**word index** into `vals` (`[vals[f68] + 0x1C8] &= ~1` when `arg1 == 1`; the
`addiu $v1,$zero,-0x2` mask is `~1`, NOT `~2` — first try got this wrong).
`arg1 == 0` arm also does `[vals[1] + 0x1C8] |= 1` (loaded via `$v0`, the dead
call register) and ends `b epi; sw` in the delay slot. Other `arg1`: just return.

Original shape: `addiu $v1,$zero,1; beql $s1,$v1,<case1>; lw $a0,0x68($s2);
beql $s1,$zero,<case0>; lw $v1,0x1C8($a0); b epi; nop` then case0 body at
+0x7C, case1 at +0x94. Both branch delay slots are filled **loads**, and the
second load's base is the first test's delay-slot load — the two `lw`s run on
