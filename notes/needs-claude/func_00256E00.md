## What it does
Searches the global table at `D_003E0BD0` (array of 0x20-byte groups, count
`D_003E0BD4` u16; see func_00256BD0/func_00257B80 for the same globals). For each
group with `count > 0` (s16 at 0x10) it walks `entries` (0x14, 0x10-byte entries)
and scans each entry's list (`s32 *items` at 0xC, word 0 of each 20-byte record,
i.e. `items[k * 5]`) for `obj->key` (0(a0)). On a hit it sets
`obj->mask |= 1 << (s8)entry->bit` (4(a0), lb then `sllv` with 1) and breaks the
inner loop. Returns -1 on every path (entry null guard `beql`+`addiu v0,-1`, tail
`b; addiu v0,-1`).
