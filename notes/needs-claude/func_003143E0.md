occupied spans read from a record table `D_003E11A0` (stride 0x19C; `lb 0x11A`
= active flag, `lh 0x13A` = start, `lh 0x13C` = length), collecting runs of
free indices `D_003E11A8 .. +D_003E11AC` into `Run {s16 start; s16 count;}`

with `func_00132330(runs, nruns, 4, func_00314560)` (comparator already
matched), and returns the start of the first run with `count >= arg0`, else 0.
