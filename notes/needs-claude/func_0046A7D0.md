  pointer regs** emitted up front.

  twin shapes: slot 0 direct `$a0` + `bnel`, slots 1/2 `addiu $v1,$a0,N` base +
  `bnez`), slot 0x18 → the f12 arg (`cvt.s.w $f12`/`lwc1 $f12`), slot 0x20 → `a2`
  (`tag == 1 ? (s32)f : i`, direct `0x24($a0)` in the `bnel` delay slot).
- `else if (mode == 1)`: slot 0x00 only → `a2` (`tag == 1 ? (s32)f : i`).
- else: nothing but `a2 = 0`.
- All three paths then call `func_1A6360(D_003E1B9C /*%gp_rel*/, &buf, a2, f12)`;
  return 1.

## The layout the original has
```
beq   $a1,5  -> float block (out of line, LAST block before the call)
 daddu $a2,$zero,$zero          ; a2 = 0 hoisted into THIS delay slot
beql  $a1,1  -> tag-test block at +0x48 (out of line), delay lw $v0,0($a0)
b     CALL                      ; else falls through, delay lw $a0,%gp(D_003E1B9C)
  [tag block] bnel ...; b MERGE; nop
  [float block] ... -> MERGE
MERGE: lw $a0,-0x56D4($gp)
CALL:  jal func_1A6360; addiu $a1,$sp,0x10; ld $ra...
```
i.e. mode==1 branches out-of-line with **beql** (tag `lw` in its delay slot), the
else falls through to a `b` into the `jal` (skipping the merge block, its a0-load
duplicated into the `b` delay slot), and `a2 = 0` lives in the FIRST beq's delay
slot. `lw $a0,%gp` appears twice: at the A/B merge and in the else's `b` slot.
