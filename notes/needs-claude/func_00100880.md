# func_00100880 — thread launcher + dead C++-EH handler block (EH wall, same as func_001007A0)

- Size 128 B (0x100880–0x100900), text_100880.s, `nonmatching func_00100880, 0x74`.
- factory-1 (Qwen) session 2026-10-21: ~7 attempts, not matched.
- funcdb: no callers, strings `std::exception`, `std::bad_alloc`.

## What it is

```
addiu $sp, $sp, -0x40
lui   $v0, hi(D_003DD680);  lui $a0, hi(D_003BE9B0);  lui $a2, hi(func_00100900)
sd    $ra, 0x10($sp);  sq $fp, 0x0($sp);  addu $fp, $sp, $zero   <- fp-style frame
addiu $v0, lo;  sw $v0, 0x3C($fp)          <- stackAddr = (u32)&D_003DD680
addiu $a0, lo;  addiu $a1, $fp, 0x3C
jal   func_00102670;  addiu $a2, lo(func_00100900)   <- launch (a0=CB, a1=&stackAddr, a2=entry)
b     .L001008E0;  nop                      <- unconditional to epilogue
jal   func_00101510;  addiu $a0, $fp, 0x20 <- UNREACHABLE terminate(&info@fp+0x20)
.L001008C4: 5x nop; b .L001008C4; nop      <- spin
.L001008E0: addu $sp,$fp; ld $ra,0x10; lq $fp,0x0; jr $ra; addiu $sp,$sp,0x40
```

`func_00102670` (see funcdb: saves s0–s7/fp + f20–f31, `paddub` sp into the
frame, tail-jumps `func_00101060($sp)`) is the scheduler's thread launch: it
switches context, so the terminate + spin block is the "thread returned"
path. `func_00101510` is the terminate/EH path (needs-claude note pilot P29).

1. Plain C, both calls live (`build/drafts/f880_a.c`): frame 0x30, `sd $ra`
   at 0, no `$fp`, no `b`, no dead block — wrong shape.
2. `try { func_00102670(...); } catch (...) { func_00101510(info);
   for (;;) { } }` in .cpp, `extern "C"` (`build/drafts/f880_c.cpp`) —
   **closest**: reproduces the fp prologue (`sq $fp 0`, `sd $ra 0x10`), the
   unconditional `b` to the epilogue, the unreachable catch (`jal
   func_00101510; 5x nop; b -6; nop` — identical instruction mix), and the
   epilogue. Remaining diffs are ONLY:
   - extra EH token registration `sw $sp, 0x34($fp)` after the call;
   - frame 0x60 vs 0x40 → locals shifted (mine `info@fp+0x40`,
     `stackAddr@fp+0x5C`; target 0x20/0x3C);
   - `addu $sp,$fp,$zero` sits in the `b` delay slot (target: `nop` there,
     `addu $sp,$fp` in the epilogue);
   - minor prologue scheduling (`addiu $v0 lo` early vs after `sq $fp`,
     `addu $fp,$sp` position).
3. Same with `return;` inside try (`f880_f.cpp`): identical to 2.
4. `__declspec(noreturn)` / `__declspec(nothrow)` on `func_00102670`: this

   untested idea in the func_001007A0 note is dead.
5. MS SEH `__try/__finally`: not supported ("undefined identifier '__try'").

## Wall

Exactly the func_001007A0 wall: CodeWarrior always emits the EH token
registration (`sw $sp,0x34($fp)`, +0x20 frame) for `try/catch`, but the
original frame has a catch-all handler laid out WITHOUT any registration.
Possibilities for Claude: registration provided by the callee/runtime
(func_00102670 stores sp in its own frame already — `sw $v0,0x14/0x1C($sp)`);
or the handler is emitted by a form of `catch` this compiler lays out
lazily; or roadmap step 7 (C++ EH) is the honest fix. Best draft:
`build/drafts/f880_c.cpp` (not in `src/`, config keeps
`[0x860, asm, text_100860]` covering 0x860–0x960).
