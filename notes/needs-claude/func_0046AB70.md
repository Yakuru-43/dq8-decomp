- Size: 240 B (0x46AB70–0x46AC60), frame 0x20, two 16-byte locals at 0x0($sp) (*a3
  copy) and 0x10($sp) (*a2 copy), each copied member-by-member with `lwc1`/`swc1`
  (4×`f32`), then read back as **ints** with `lw`.
- What it does: byte blit. For each row of the rect held in *a2 (read as ints:
  [0]=dst y, [1]=dst x, [2]=height, [3]=width), for each col, copy one byte from
  `a1->pixels + sx + a1->w * (a1->stride - sy)` (w=stride read with `lh` at +0x2/+0x4,
  buffers are `lw` at +0x50) into `a0->pixels + dx + a0->w * (a0->stride - dy)`.
  sx/sy start at *a3[1]/[0] (ints), dx/dy at *a2[1]/[0]. `src->stride` is reloaded
  with `lh` in the inner `bnel` delay slot. Returns 1 always. Both loops are plain
  bottom-tested `while`s entered by a `b` to the test; control flow, branch offsets
  (0x17/0x10/0x11/0x18) and the whole loop body matched from the first draft.

    Rect d = *dstRect;
    u8 *db = dst->pixels;

    s32 sy = *(s32 *)&s.top;

        s32 dx = dx0;

            *(u8 *)(db + dx + dst->width * (dst->stride - dy)) = val;

    return 1;
