## The one diff that matters: `andi` vs the `dsll32`/`dsra32` pair

Every loop body in the original passes the byte value with the EE pair
`dsll32 a?, c, 24` (c << 56) + `dsra32 a?, a?, 24` (unsigned >> 56) — zero-extend
of the `lb`-loaded s8 to a clean u8 in a 64-bit register. My C gets
`andi a?, v?, 0xFF` (one instruction, placed in the branch delay slot), so each
loop comes out 4 bytes short and everything shifts (that is the whole score=51).
