## Analysis

CodeWarrior always constant-folds this CFG (`if` whose arms both `return 0`) down to a
bare `return 0`; nothing in plain C keeps a branch whose arms are identical. The original
must have had something in one arm that vanished **after** compilation — e.g. a vendor
patch that stripped a call from the taken arm (compare `func_0023E6A0`, whose arm is
intact: same guard, full body). If so no C can match and this belongs to `asmfunc/`.
