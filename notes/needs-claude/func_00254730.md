   testing directly (e.g. is the sum's only "use" a later `adda.s`? write
   `sum += x; sum += y;` and check if CW kills it at -O3).

   computes `src2b + t*(src1b-src2b)` (madd fd = the (f32)(u32)b reg,

   `base + t*(f32)d` (byte) — same as the asm, but see the DCE issue: maybe
   both regions share ONE inline lerp helper whose shape makes CW emit both
   madd forms depending on the conversion path.
3. Block layout: first diff is the destination of `beqz $s5` at +0x3C
   (everything after shifts — the return stubs for the three early returns
