## What it does

Parses a grid reference string like `"ab_12"` and writes a 16-byte 4-float
struct (Vec4-shaped) at `a1`, returning 1 on success, 0 on any test failure:

- `a0 == NULL` → 0; `a0[1] != '_'` → 0; `a0[0] < 0x61 || a0[0] >= 0x77` → 0
  (the two range tests share the stub at 0x199FC4);
- `value = func_0012D528(a0 + 2)`; `value < 0` → 0; `value >= 100` → 0
  (both share the stub at 0x199FCC);
- if `mode != 0`: `out->x = 4000.0f * (f32)value + (f32)-56000`,
  `out->y = 0.0f` (stored as `sw $zero`),
  `out->z = 4000.0f * (f32)(a0[0] - 0x61) + (f32)-40000`,
  `out->w = 1.0f` (stored as `lui $v0, (0x3F800000 >> 16)` + `sw $v0, 0xC($s1)`
  — an integer-path store of the float bits);
- if `(u32)(mode - 1) < 2`: re-parse `value = func_0012D528(a0 + 2)` and store
  the same fields with scale `16000.0f` (0x467A0000);
- return 1.
