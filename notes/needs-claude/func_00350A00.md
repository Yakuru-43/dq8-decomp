## What it is

32 B, 0x350A00–0x350A20, `asm/SLES_539.74/game_3506C0.s`.

```

jal   func_003515A0
nop
ld    $ra, 0x0($sp)
```

Call-only wrapper around `func_003515A0()` (matched: `s8 func_003515A0(void)
{ return D_003E1378; }`). Passes no args (callers in game_17BA90.s set a0 in
*their* delay slots), sets no return value. Byte-identical shape to
`func_00100860`/`func_00100780` (notes/needs-claude) — the "boot wrapper"
wall, but this one sits in normal game text at 0x350A00 where the neighbours
are plain `-O3` CW.

## Attempts (factory-3, 2026-10-31, ~9, all -O3 unless noted)

- `void(void)` + `M2C_UNK f();` / `s32 f();` / `f32 f();`, with or without
  explicit `return;` → tail jump `j func_003515A0; nop` (8 B).
- `s32` wrapper `return func_003515A0();` → tail jump.
- One-trip `s32 n = 1; do { f(); } while (--n != 0);` → CW keeps the loop

  `-opt tailcall,off` epilogue schedule differs from the -O3 schedule of
