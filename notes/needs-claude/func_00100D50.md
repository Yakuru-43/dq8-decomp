# func_00100D50 — BootCb list walker, one nop short of a match

CLASS structural score=5 (4 words differ, 80 vs 84 bytes) — best attempt, 8 attempts.
All four differing words are: 2 masked relocation lines (`lui`/`lw` %hi/%lo of
D_003E1D00), the `beqz` jump offset (+0xC vs +0xD), and **one missing `nop` at
+0x44 (0x100D94)** before the epilogue. Everything else matches word for word.

- Size: 0x54 (queue size 96 incl. padding), `asm/SLES_539.74/text_100A40.s`.
- What it does: walks the global BootCb list at D_003E1D00 (same list as the
  matched `func_00100DB0.c`, which links nodes in), pops each node into the
  head and calls `node->fn(node->arg, -1)` until the head is 0. The
  `fn(arg, -1)` matches the `destroy(p, -1)` idiom of the matched
  `func_00100480`.
- Update 2026-10-26: the earlier "gp-relative wall" note (commit 89424f9) is
  **gone** — declaring `extern char D_003E1D00[]` with casts, as the matched
  `func_00100DB0.c` does, gives the absolute `lui %hi` / `lw/sw %lo` pairs and
  the original's register allocation (`node` in `$a2`). Only the padding nop

## What was tried

1. `while ((node = *(BootCb **)D) != 0) { ... }` — CW loop-rotates: initial
   `b` to a bottom `bnel` with `lw v1,0(a2)` in its delay slot. Same for the
   pre-load + bottom-reload `while` form.
2. Guard `if (node == 0) return;` + `do { body; node = *D; } while (node != 0);`
   — exact shape, **score 5**, missing nop (best).
3. Same with the tail reload as a statement vs. inside the condition — identical.
4. `if (node != 0) { do { ... } while (...); }` (no early return) — identical.
5. Guard + `for (;;) { ...; if (node == 0) break; }` — identical (score 5).
6. `while (node != 0)` + tail `if (node == 0) return;` — CW re-rotates badly
   (`beqz`+`bnel` with delay-slot fill), score 18.
7. Un-guarded do-while + tail `break` + redundant condition — a live forward
   `beqz` survives at +0x34, score 18.
8. `tools/permute.py func_00100D50 --run 600` — cannot run on this host
   (`FileNotFoundError: cpp`).
