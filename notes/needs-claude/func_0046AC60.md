# func_0046AC60 (CASINO, 0x0046AC60, 448 bytes incl. padding; code ends 0x0046AE10)

Splits `value` into decimal digits: counts digits (loop 8x, mul *= 10),
allocates `count * 4` bytes via `func_100860`, fills `buf[i] = value / 10^i`
from the top down with `value -= buf[i] * 10^i`, then `memset`s `dst`
(`func_131188(dst, 0, len)`) and writes each digit as two bytes:
`(d + 0x7FFF + 0x250) >> 8` (masked 0xFF00) and the low byte. Frees via
`func_100780`, returns digit count.
