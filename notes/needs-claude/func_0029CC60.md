## Mechanism (new finding — helps CC00 and the whole family)
In every guard chain in this file that CW compiles WITHOUT mirroring
(CB00/CB80 guards, our guards 1–2), the instruction after the guard
overwrites `$v0` (`lbu $v0,N($a1)`), so it cannot legally occupy the
branch delay slot and CW is forced into direct-to-epilogue + `daddu`
delay. Guard 3's continue block starts with `lw $a0,0x1C($a1)` — $v0-safe —
so CW grabs it for the delay slot and mirrors the branch. Five source
shapes (plain guards, struct members, load hoisted above the guard,
nested if/else with single return) all hit score 10. The original source
must make the node load unfetchable for the delay slot. Ideas not tried:
load the node via a helper or volatile-free double use that keeps $a0
live on both paths; pass `arg1->node` directly into the call and read
`->unk10` from a separately-scheduled expression; or a `u32` node idiom
(SKILL branch-likely idiom) so the test reg differs.
