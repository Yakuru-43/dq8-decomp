## Why the naive forms fail (2026-10-27 session, 9 attempts)

- Plain chain `if (s==1){body} if (s==3) ret0; if (s!=2) ret0; return 0;`
  -> CW value-range-folds: after !1 && !3, `if (s!=2){ret0} return 0;` is
  all-exits-identical, second test deleted -> 140 bytes, CLASS structural
  score=27.
- `if (s == 3 || s != 2) { return 0; } return 0;` -> folded harder: 128
  bytes, score=30. CW proves the || covers all modes but 2 and both arms
  return 0.
- One full `switch (mode) {case 1: body/ret1; case 3: ret0; default:
  if (s!=2) ret0; break;} return 0;` -> CW hoists the switch's ==3 test
  above the beq(1) test (first word of chain becomes addiu 3) and folds
  the default guard: 144 bytes, score=31.
- `if (s==1) {...} switch {case 3: ret0; case 2: break; default: ret0;}`
  -> 152 bytes, score=3: chain = `beql(2), beql(3)` (ascending value order)
  instead of `beql(3), bnel(2)`. Putting `default:` first in source does
  not change the test order; it only fixed the order once `if (mode==3)`
  was lifted out of the switch (the score-1 form above).
