## What I tried
1. Plain `if (reader->field_04 >= reader->field_08)` → loads swapped (v0/f04
   first). **`field_08 <= field_04` gives the right order** (`lw v1,8` then
   `lw v0,4` + `sltu at,v0,v1`) — used from then on.
2. `(byte != -1) != false` → CW simplifies to `not/sltu $zero` (no xori).
3. `(byte == -1) == false` inline → right `not/sltiu` generation but CW folds
   `== false` into `bnez`; the orig keeps `xori 1` + `beqz`.
4. `bool isByte = byte != -1; if (isByte)` → folds all the way to
   `addiu v0,-1; beq s0,v0` (and inverted).
5. `left = reader->field_08 - 1` hoisted before the if → CW CSEs it with the
   guard load, so **no reload at +0x5C** (reuses the guard's v1); orig reloads.
6. `bool missing = byte == -1; if (missing == false)` → best: right bool
   generation, still folded to bnez, still no reload.
7. `if (func_00135DF8(...) == -1)` (no result local) → identical codegen,
   keeps frame at 0x20 with only s0 saved (a result local did not spill).
