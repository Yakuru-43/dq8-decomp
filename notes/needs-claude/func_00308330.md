## The stubborn diff (head block)
Original emits, after the guard: `addiu $a3,$zero,1` (mask const in **$a3**), then the
`/32` block, then the `%32` block, then `sllv $a3,$a3,$v0`, `sll $v0,$v1,2`,
`addu $v0,$v0,$a0`. CW schedules the **bit block first** in every draft variant above:
`addiu $v1,$zero,1` … `andi $v0,$a1,0x1F`/`beqz`/`addiu -0x20` … `sllv $a3,$v1,$v0` …
then the `bgez/sra` word block into `$v0` … `sll $v0,$v0,2; addu $v0,$a0,$v0`.
So both the register pick for the `1` (v1 vs a3 — a *consequence* of the schedule, since
v0/v1 are live in the reordered blocks) and the div/mod block order are wrong.
