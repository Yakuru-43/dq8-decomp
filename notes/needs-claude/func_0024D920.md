## What it does
Size 0xB0 (176 B incl. padding), range 0x24D920..0x24D9D0,
`asm/SLES_539.74/game_24D83C.s`. `*arg2 = 0;` then searches the 16-byte
record table `D_003E0B5C` (count `D_003E0B58`, s16) for `entry->id == arg0`;
null table or not-found means `return 0`. On a hit: `arg1 == 0` passes
`entry->unk04`, `arg1 == 1` passes `(s32 *)((char *)entry + 8)[arg3]`
(emitted `sll a3,2; addu v0,v0,t1; lw a1,8(v0)`); zero means `return 0`,
else `func_001340C0(arg2, value); return 1;`. Other `arg1` means `return 0`.
Same table family as matched `func_0024C2C0.c` (which allocates it,
records `D_003E0B58 * 0x10` bytes).
