- Size: 192 B, range 0x14E640 0x14E700 (3 padding nops), asm in

- What it does: heap gap-splitter. Walks a doubly-linked list of 16-byte
  nodes starting at `*(list + 0x18)`; between `node` and `node->next` looks
  for a gap of `>= size + align` (16-byte units, unsigned compare); writes a
  new node at the gap start, links it in (reloading `end->next` after the
  stores), stores `size + align` as the node size, rounds the block end up so
  `(addr >> 4) % align == 0` (`%` → divbyzerocheck guard: `bnez a2` / `divu` /
  `break 0,7` / `mfhi`), stores the block length in units at `end->gap` and
  duplicates it into the tail word `(end_aligned)[-1].gap` (the sibling
  free func_0014E500 reads that word back). Returns the aligned block start
  (`end + 1` rounded) or 0 (`daddu $v0,$zero,$zero`).
