#include "common.h"

s32 func_00210A90(s32 arg0, u8 *arg1, s32 arg2) {
    s32 i;
    s32 count;
    s32 sum;

    if (arg0 != 0) {
        return 0;
    }
    count = arg2 < 0 ? (arg2 + 0x3F) >> 6 : arg2 >> 6;
    sum = 0;

        i++;
    }
    return sum;
}

## The wall (6 words, all one regalloc + one likely bit)

```
* +008  bgezl       $a2, +3        bgez        $a2, +3      <- likely bit
* +00C  sra         $a2, $a2, 6    sra         $a3, $a2, 6  <- count: mine a2, orig a3
* +014  sra         $a2, $v0, 6    sra         $a3, $v0, 6
* +01C  daddu       $a3, $zero     daddu       $a2, $zero   <- i: mine a3, orig a2
* +034  addiu       $a3, $a3, 1    addiu       $a2, $a2, 1
* +03C  slt         $v1, $a3, $a2  slt         $v1, $a2, $a3
```
Everything else (guard, delay-slot `lbu`, `div`/`mfhi` loop, `b .L` entry jump) matches byte for byte.

The original keeps `arg2` in `$a2` live across the count block (read at +0x0C *and* +0x10), so
`count` must live in `$a3` and `i` gets `$a2` at +0x1C. CodeWarrior here instead schedules
`sra $a2, $a2, 6` into a **branch-likely** delay slot — legal only because the not-taken path
skips the delay slot — which frees it to keep `count` in `$a2`. Same s0/v0-style regalloc wall as
`func_002106E0` (see its note). `tools/permute.py` cannot run in this worktree: the permuter
subprocess dies with `FileNotFoundError: 'cpp'` (no C preprocessor on this host).

## What was tried

1. `if (arg2 >= 0) {..} else {..}` guard-first (`>= 0`): CW emitted `bltzl` + `b` (5 words → 84 B).
2. Same with `count`/`i` declarations swapped: no change (declaration order irrelevant).
3. Unconditional `count = arg2 >> 6;` + `if (arg2 < 0) { override }` (the shape that would force
   plain `bgez` + always-executed delay `sra` and push `count` to `a3`): CW laid the if body out
   out-of-line (cold), `bltz` to tail + duplicated loop entry — 92 B.
4. Ternary form (best, score 6) and if/else with explicit `s32 tmp = arg2 + 0x3F` — byte-identical results.
5. Nested single-exit `sum = 0; if (arg0 == 0) { ... } return sum;`: `bnez` not `bnel`, lost the
   `daddu $v0` duplicate at +0x18, 76 B — worse.
6. Finishing permute: impossible here (missing `cpp`, above).
