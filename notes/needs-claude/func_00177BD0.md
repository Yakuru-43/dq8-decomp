## The mystery: `mtc1 $zero,$fN; adda.s $fN,$fM` = 0.0f + base

Every element re-zeroes an FPR and adds the base, instead of `mov.s` or
comparing against the base register directly (my plain `if (val < base)`
compares f1,f2 with no adda). Read the MH2 **Float code** section (line 3551):
nothing there explains 0+x. Suspect a float expression like
`if (val < 0.0f + base)` kept unfolded (signed zero), an accumulator local
(`f32 lo = 0.0f; lo = lo + fx->f_10;`), or a member getter. A matched example
would settle it — none found in src/ yet.
