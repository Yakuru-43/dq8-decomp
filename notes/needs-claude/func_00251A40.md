# func_00251A40 (0x251A40, 320 bytes incl. padding, SLES_539.74)

Sema-guarded ring-buffer **peek**, sibling of func_002517D0 / func_00251600 /
func_002510D0 (read those notes first — same file `game_2514B0.s`, same
`struct SemaRing { u32 unit; ?pad04; u32 size; volatile s32 sema@0xC; u32
rd@0x10; u32 wr@0x14; u8 full@0x18; u32 out@0x1C; ?pad20; u32 flush@0x24; }`).
`s32 f(Ring *ring, s32 *countOut, s32 *sizeOut)`, frame 0x50, `sd ra,0x30;
sq s2,0x20; sq s1,0x10; sq s0,0`; $s2=ring, $s1=countOut, $s0=sizeOut.

- Entry: `addiu v1,s2,0xC; lw v0,0xC(a0); bgtz v0,cold; sw v1,0x4C(sp)` —
  sema pointer temp + spill **in the bgtz delay slot** (family blocker 1).
  cold `jal WaitSema; lw a0,0(v1); b back; lw v1,0x14(s2)`.
- avail/wrap/round-down and flush blocks are byte-identical in shape to the
  flush block of func_002517D0 (see that note): `beql a0,zero,B4 [delay lbu
  0x18]`, `blezl a0,C4 [delay lw 0x8]`, `count = avail/unit*unit` (`mult a1`),
  flush `room = flush - out(0x1C)`, `bltzl room→0`, `room % unit != 0 →
  count = unit*(room/unit + 1)` else keep, `slt at,a0,a1; daddu a1,a0` clamp.
  **No consume path**: instead the tail is
  `sw a1,0(s1); lw v0,0x8(s2); lw v1,0x4C(sp); sw v0,0(s0); lw s0,0x10(s2)` —
  `*countOut = count; *sizeOut = ring->size;` then **$s0 is reloaded with
  ring->rd** (`lw s0,0x10(s2)`), signal guard inline
  `lw v0,0(v1); blez v0,skip; nop; jal SignalSema; lw a0,0(v1)` (family
  blocker 2), `b epi; daddu v0,s0` → **returns ring->rd**.

## Blockers (the family's, verbatim — see func_00251600.md "Blockers")

1. Sema pointer temp: any named `volatile s32 *id` local (or the inline
   `SemaId()` accessor) → extra callee-saved reg + frame 0x60; orig keeps it
   $v1 + stack slot 0x4C(sp), materialized before the wait test, spilled in
   the `bgtz` delay slot, reloaded (`lw v1,0x4C(sp)`) only for the signal
   guard's `lw v0,0(v1)` / `lw a0,0(v1)`.
2. Signal-guard polarity: orig `blez` + `nop` + `jal SignalSema` INLINE; CW
   inverts `if (*id > 0) SignalSema(*id);` to `bgtzl` + out-of-line.
3. `$s0` reused: sizeOut dies after `sw v0,0(s0)` and `lw s0,0x10(s2)`
   reloads rd into it, returned via `daddu v0,s0`. A plain `return ring->rd;`
   in C keeps rd in $v0 and never touches $s0 again — needs the reload into
   the dead sizeOut register.
