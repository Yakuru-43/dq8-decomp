# func_002103D0 (0x2103D0, 228 B)

Copies up to `min(n, 30)` entries of 0x50 bytes from `obj + i*0x50 + 0x6BF0`
(entry address via `func_002104C0(obj, i)`, memcpy via `func_00130FD0`) into
`buf + i*0x50`, counts entries whose first byte is nonzero (return value) and
whose second byte is also nonzero (stored through `out` when non-null).
Sibling shape: `func_00210370/80` and `func_002104C0` in the same TU use the
same `0x6BF0`/`0x50`/`30` layout, so `a0` is the same object as their arg0.

## Best C (try_match score 16, everything matches except the prologue)

```c
// range: 0x2103D0 0x2104C0
#include "common.h"

M2C_UNK func_00130FD0(s32, s32, s32);               /* extern */
s32 func_002104C0(s32, s32);                        /* extern */

s32 func_002103D0(s32 obj, s32 buf, s32 n, s32 *out) {
    s32 countA;
    s32 countB;
    s32 i;
    s32 dst;
    s32 entry;

    if (n >= 30) {
        n = 30;
    }
    countA = 0;
    countB = 0;
    for (i = 0; i < n; i++) {
        dst = buf + i * 0x50;
        entry = func_002104C0(obj, i);
        func_00130FD0(dst, entry, 0x50);
        if (*(char *)dst != 0) {
            countA++;
            if (*(char *)(dst + 1) != 0) {
                countB++;
            }
        }
    }
    if (out != 0) {
        *out = countB;
    }
    return countA;
}
```

## What still differs (everything from +0x38 on matches exactly)

Register mapping of the two int-ish params: original `daddu $s4, $a2`
(`n` -> s4) and `daddu $s5, $a3` (`out` -> s5); mine swaps them
(n -> s5, out -> s4, so `slti`/`slt`/`beqz`/`sw` all use the wrong s-reg).
Original also hoists the clamp test above the spill block and tests the raw
parameter: `slti $v0, $a2, 0x1E` sits at +0x4 (right after `addiu $sp`),
while mine emits `slti $v0, $s5, 0x1E` at +0x28 after the param copies.
The prologue copy/sq interleave differs only because of these two facts:

```
orig:  +000 addiu sp | +004 slti v0,a2,1E | +008 sd ra | sq s7 | daddu s7,a1
       sq s6 | daddu s6,a0 | sq s5 | daddu s5,a3 | sq s4 | daddu s4,a2 | sq s3
       | sq s2 | sq s1 | bnez v0 | sq s0 | addiu s4,zero,1E
mine:  +004 sd ra | sq s7 | sq s6 | daddu s7,a1 | sq s5 | daddu s6,a0 | sq s4
       | daddu s5,a2 | sq s3 | slti v0,s5 | sq s2 | daddu s4,a3 | sq s1 | bnez
```
