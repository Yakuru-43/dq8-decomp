## What it does
Meter/progress-bar animator over `arg0`. Guard `0x208` (active); per-entry loop
i = 0..11 over 16-byte-strided slots at `(char *)arg0 + (i << 4) + 0x3C`
(f32); `0x210` = state (1 = ramp up to clamp 128.0f, 2 = ramp down to 0.0f);
`0x214` = tick; `0x20C` = speed; `0x1FC` = last slot value. When tick == 0
speed is (re)computed as `(128.0f - slot) / 6.0f` (state 1) or `-slot / 6.0f`
(state 2); each pass `slot += speed` clamped; tick > 6 (and the tick test with
0x2E after the loop) force the slot and reset state/tick. No calls, no saved
registers, everything in temporaries: i in `$a1`, slot base `$a2`, slot pointer
`$a3`, constants `$t0`=2, `$t1`=0x43000000, `$f1`=6.0f, `$f2`=0.0f, `$f4`=128.0f.
