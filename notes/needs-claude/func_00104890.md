# func_00104890 — Reader seek with access-code switch

- size: 368 B, range 0x104890 0x104A00, `asm/SLES_539.74/text_104890.s`
- Neighbours `func_001046C0`/`func_00104780` are matched (same Reader struct).

## What it does
`func_00104890(Result *result, Reader *reader, s64 pos, u8 code, u8 flags)`:
fail (sd -1 / sw 0) if `reader->field_1C == 0`; if `field_14 > field_10` flush via
`v_0x34(-1)` into an int `bad` flag tested separately (`bnel $s0`); switch over
`code`: 4→whence 2, 2→ `(u8)(flags & 8) == 0` → whence 1 else `pos -=
(s32)(field_0C - field_08)` (whence **not assigned** on that path — the original
keeps whence in dead-incoming `$a2`), 1→whence 0, default fail; then
`func_0012F488(field_1C, pos, whence)`, on 0 clear fields 04/08/0C/14/10/18/34
(that order) and `result->field_00 = func_0012F998(field_1C)` (sd $v0, no sext).

## Why it is stuck (register allocation / block placement)
- original: saved s0=bad s1=flags s2=code s3=pos s4=reader s5=result, ra;
  `whence` lives in **$a2** (the dead incoming pos reg): the case stores are
  `addiu $a2, zero, 2/1/0` and the call reads $a2 directly. Mine always pulled
  `whence` into a saved reg ($s0/$s1) and `flags` into $s1/$s6, growing the
  frame to 0x80 (orig 0x70).
- original places the vtable block out-of-line after the 964/970/9A8 fail
  blocks, with both outcomes branching **back** to `bnel $s0` at 0x1048E0;
  mine inlines it after the 940 region.
- original compares `beql` for code 4/2/1; my case-1 path came out `bnel`+delay.

```c
// range: 0x104890 0x104A00
#include "common.h"
extern "C" {
extern s32 func_0012F488(void *, u64, s32);
extern s64 func_0012F998(void *);
struct Reader { /* 12 virtuals as in func_00104780.cpp */ };
struct Result { s64 field_00; u32 field_08; };

void func_00104890(struct Result *result, struct Reader *reader, s64 pos,
                   u8 code, u8 flags) {
    s32 check;
    s32 whence;
    s32 bad;

    if (reader->field_1C == 0) { result->field_00 = -1; result->field_08 = 0; return; }
    bad = 0;
    if (reader->field_14 > reader->field_10) {
        check = reader->v_0x34(-1);
        if (check == -1) { bad = 1; }
    }
    if (bad != 0) { result->field_00 = -1; result->field_08 = 0; return; }
    if (code == 4) { whence = 2; }
    else if (code == 2) {
        if ((u8)(flags & 8) == 0) { whence = 1; }
        else { pos -= (s32)(reader->field_0C - reader->field_08); }
    }
    else if (code == 1) { whence = 0; }
    else { result->field_00 = -1; result->field_08 = 0; return; }
    if (func_0012F488(reader->field_1C, pos, whence) != 0) {
        result->field_00 = -1; result->field_08 = 0; return;
    }
    reader->field_04 = 0; reader->field_08 = 0; reader->field_0C = 0;
    reader->field_14 = 0; reader->field_10 = 0; reader->field_18 = 0;
    reader->field_34 = 0;
    result->field_00 = func_0012F998(reader->field_1C);
    result->field_08 = 0;
}
}
```
