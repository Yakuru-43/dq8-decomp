## What it is

Virtual-base **this-adjust thunks**. `func_00103600`'s note
(`func_00103600.md`) shows the callee class stores exactly
`(char *)obj + 8 - obj->0` at `+0x48` of the sub-object — the vbase
displacement these thunks read. The callees are the virtual-base
constructors/destructors of the same family (`func_00103600`/`func_001036A0`
need Claude already; `func_001030B0`/`func_00103150` are their siblings).
This is CodeWarrior-generated thunk code with no source expression that
reproduces it — per SKILL.md's base-class-pointer idiom these belong to the
C++/thunk decision, not to a forced C imitation.
